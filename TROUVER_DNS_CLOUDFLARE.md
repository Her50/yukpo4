# 🔍 Où Trouver DNS dans Cloudflare

## 🎯 Plusieurs Endroits Possibles

### **Option 1 : Menu de Gauche (Le Plus Commun)**

1. **Regardez le menu de gauche** (sidebar)
2. **Cherchez "DNS"** dans la liste
3. **Cliquez sur "DNS"**

**Note** : Parfois "DNS" est dans une section "Configuration" ou "Réseau"

---

### **Option 2 : Onglets en Haut**

1. **Regardez en haut de la page principale**
2. **Vous verrez des onglets** comme :
   - Aperçu
   - DNS
   - SSL/TLS
   - etc.
3. **Cliquez sur l'onglet "DNS"**

---

### **Option 3 : Menu Hamburger (Mobile/Tablette)**

1. **Si vous êtes sur mobile/tablette**, cherchez le **menu hamburger** (☰)
2. **Ouvrez le menu**
3. **Cherchez "DNS"**

---

### **Option 4 : Recherche**

1. **En haut à droite**, il y a une **barre de recherche** avec "Allez à... Ctrl + K"
2. **Tapez "DNS"**
3. **Sélectionnez "DNS"** dans les résultats

---

## 📋 Alternative : Aller Directement aux Enregistrements

Si vous voyez **"Enregistrements DNS"** quelque part (peut-être dans la sidebar droite ou dans une section), **cliquez dessus** → Cela vous amènera directement à la page DNS.

---

## 💡 Astuce

**Dans Cloudflare, DNS est toujours accessible**. Si vous ne le voyez pas :
1. **Scrollez** le menu de gauche
2. **Ou utilisez la recherche** (Ctrl + K)
3. **Ou regardez les onglets** en haut
