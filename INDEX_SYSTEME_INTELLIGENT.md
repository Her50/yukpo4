## 🎓 Glossaire

| Terme | Définition |
|-------|------------|
| **CategoryConfig** | Configuration complète d'une catégorie (terminologie + filtres + style) |
| **Terminology** | Ensemble des labels adaptés (productLabel, priceLabel, etc.) |
| **CategoryFilter** | Un filtre spécifique (type, id, options, etc.) |
| **dominantCategory** | Catégorie la plus fréquente dans les résultats |
| **contactMethods** | Ordre de priorité des moyens de contact |
| **displayPriority** | Ordre d'affichage des informations importantes |
| **cardLayout** | Type d'affichage (horizontal, vertical, grid) |
