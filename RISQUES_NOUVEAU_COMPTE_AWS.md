# ⚠️ Risques : Créer un Nouveau Compte AWS

**Date** : 2026-02-14  
**Contexte** : Compte actuel avec facture impayée de 600$+

---

## 🔍 CE QU'AWS VÉRIFIE

### 1. Email
- ✅ **Vérifié** : Email doit être différent
- ⚠️ **Risque** : Si même domaine, peut être détecté

### 2. Carte de Crédit
- ✅ **Vérifié** : Même carte = lien détecté
- ⚠️ **Risque** : AWS peut bloquer si facture impayée sur autre compte

### 3. Adresse IP
- ✅ **Vérifié** : OUI, AWS vérifie l'IP
- ⚠️ **Risque** : Même IP = lien détecté
- 💡 **Solution** : Utiliser VPN ou autre réseau

### 4. Adresse de Facturation
- ✅ **Vérifié** : Même adresse = lien détecté
- ⚠️ **Risque** : Suspension possible

### 5. Numéro de Téléphone
- ✅ **Vérifié** : Même numéro = lien détecté
- ⚠️ **Risque** : Suspension possible

### 6. Nom
- ⚠️ **Peut être vérifié** : Même nom = lien possible

---

## ⚠️ RISQUES PRINCIPAUX

### Risque 1 : Détection du Lien
**Si AWS détecte le lien** :
- ❌ **Suspension** du nouveau compte
- ❌ **Demande de paiement** de l'ancienne facture
- ❌ **Suspension** possible des deux comptes

### Risque 2 : Violation des Conditions
**Créer un nouveau compte pour éviter une facture** :
- ❌ Peut violer les **conditions d'utilisation AWS**
- ❌ Peut entraîner une **suspension permanente**

### Risque 3 : Facturation
**Même si le compte est créé** :
- ⚠️ AWS peut **lier les comptes** plus tard
- ⚠️ Peut **demander le paiement** de l'ancienne facture

---

## 💡 SI VOUS CRÉEZ QUAND MÊME UN NOUVEAU COMPTE

### Checklist Minimale

**Pour minimiser les risques** :
- [ ] **Email** : Complètement différent (nouveau domaine si possible)
- [ ] **Carte** : Différente (ou prépayée)
- [ ] **IP** : VPN ou autre réseau (mobile, café, etc.)
- [ ] **Adresse** : Différente
- [ ] **Téléphone** : Différent
- [ ] **Nom** : Différent (si possible)

### Solutions Techniques

**Pour l'IP** :
- ✅ Utiliser un **VPN** (ExpressVPN, NordVPN, etc.)
- ✅ Utiliser un **réseau mobile** (tethering)
- ✅ Utiliser un **autre réseau** (café, bibliothèque, etc.)

**Pour la carte** :
- ✅ Utiliser une **carte prépayée**
- ✅ Utiliser une **carte d'un autre compte bancaire**
- ✅ Utiliser une **carte d'un proche** (avec autorisation)

---

## ✅ RECOMMANDATION FINALE

### Option 1 : Contacter AWS (Recommandé)
- ✅ **Meilleure option** : Résoudre le problème légalement
- ✅ **Pas de risque** : Pas de suspension
- ✅ **Solution propre** : Compte en règle

### Option 2 : Créer un Nouveau Compte (Risqué)
- ⚠️ **Risque élevé** : Détection possible
- ⚠️ **Violation possible** : Conditions d'utilisation
- ⚠️ **Solution temporaire** : Peut être suspendu plus tard

---

## 📋 PLAN D'ACTION

**Si vous créez un nouveau compte** :
1. ✅ Contacter AWS d'abord (pour documenter la tentative)
2. ✅ Attendre la réponse AWS
3. ✅ Si refus, créer le nouveau compte avec toutes les précautions
4. ✅ Utiliser VPN pour l'IP
5. ✅ Utiliser carte différente
6. ✅ Utiliser email différent

**⚠️ Même avec toutes ces précautions, le risque existe !**
