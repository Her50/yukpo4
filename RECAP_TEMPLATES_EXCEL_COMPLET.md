## 💾 SAUVEGARDE EN BASE DE DONNÉES

### Structure JSONB `data->produits`
Chaque produit est sauvegardé avec **TOUS ses champs spécifiques** dans le JSONB `produits` de la table `services`.

#### Exemple Clinique :
```json
{
  "id": "prod-123",
  "type": "hopital_clinique",
  "nom": "Clinique Saint-Joseph",
  "prix": 0,
  "devise": "XAF",
  "description": "Clinique privée spécialisée",
  "typeEtablissement": "Clinique",
  "banqueSang": false,
  "prestationsMedicales": ["Gynécologie", "Ophtalmologie", "Pédiatrie"],
  "planningHebdomadaire": {
    "Lundi": {"debut": "09:00", "fin": "19:00", "permanent": false},
    "Mardi": {"debut": "09:00", "fin": "19:00", "permanent": false},
    ...
  },
  "rdvEnLigne": true
}
```

#### Exemple Déménagement :
```json
{
  "id": "prod-456",
  "type": "demenagement",
  "nom": "Déménagement Express",
  "prix": 50000,

  "volumeEstime": "20",
  "typeVehicule": "Camion 20m³",
  "distanceKm": "50",
  "nbDemenageurs": "3",
  "assuranceMarchandise": true,
  "serviceManutention": true,
  "montageDemontage": true,
  "emballageCartons": false,

  "debarras": false
}
```
