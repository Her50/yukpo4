# 📍 Où Trouver les Serveurs de Noms Cloudflare

## 🎯 Sur la Page Actuelle (Aperçu)

### **Les serveurs de noms sont affichés sur cette page !**

Regardez dans la section principale, vous devriez voir :

**"Serveurs de noms Cloudflare"** ou **"Nameservers"**

Ils ressemblent à :
```
ns1.cloudflare.com
ns2.cloudflare.com
```

Ou parfois :
```
alex.ns.cloudflare.com
sue.ns.cloudflare.com
```

---

## 🔍 Si Vous Ne Les Voyez Pas Immédiatement

### **Option 1 : Scroller vers le bas**

Les serveurs de noms peuvent être affichés plus bas sur la page, dans une section dédiée.

### **Option 2 : Aller dans la Section DNS**

1. **Dans le menu de gauche**, cliquez sur **"DNS"**
2. **En haut de la page DNS**, vous verrez une section **"Serveurs de noms"** ou **"Nameservers"**
3. Les 2 serveurs seront affichés là

---

## 📋 Format des Serveurs de Noms

Cloudflare vous donnera **2 serveurs de noms** qui ressemblent à :

**Format 1** (Standard) :
```
ns1.cloudflare.com
ns2.cloudflare.com
```

**Format 2** (Personnalisé) :
```
alex.ns.cloudflare.com
sue.ns.cloudflare.com
```

**Format 3** (Avec numéro) :
```
ns1.yukpomnang.com.ns.cloudflare.com
ns2.yukpomnang.com.ns.cloudflare.com
```

**Peu importe le format**, utilisez les 2 serveurs exactement comme affichés.

---

## ✅ Action dans Namecheap

Une fois que vous avez les 2 serveurs :

1. **Allez dans** : https://www.namecheap.com
2. **Connectez-vous**
3. **Domain List** → Cliquez sur `yukpomnang.com`
4. **Advanced DNS** → **Nameservers**
5. **Sélectionnez** : "Custom nameservers"
6. **Entrez les 2 serveurs Cloudflare** (exactement comme affichés)
7. **Sauvegardez**

---

## 🔍 Capture d'Écran - Où Chercher

Sur la page Cloudflare, cherchez une section qui dit :

- **"Serveurs de noms Cloudflare"**
- **"Nameservers"**
- **"Mettez à jour vos serveurs de noms"**

Les serveurs sont généralement affichés dans une **boîte grise** ou **encadré** avec les 2 adresses.

---

## 💡 Astuce

Si vous ne voyez toujours pas les serveurs :

1. **Regardez tout en bas de la page** (scroller)
2. **Ou cliquez sur "DNS" dans le menu de gauche**
3. **Les serveurs sont toujours visibles quelque part** sur la page de configuration
