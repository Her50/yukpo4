🎯 SCRIPT VIDÉO PRESTATAIRES - YUKPO

Présentation Directe : 1 Minute

Document de production pour spécialistes du montage vidéo IA
Durée totale : 60 secondes maximum

🎯 Objectif : Présenter simplement et directement l'intérêt de Yukpo pour TOUS les types de prestataires. Message clair, concis, actionnable.

🎬 Style : Direct, professionnel, rythmé. Pas de longue introduction émotionnelle. On va droit au but.

PARTIE 1 : ACCROCHE (0:00 - 0:10)

0:00 - 0:10 Question Directe

Concept : Question qui interpelle immédiatement tous les prestataires

Narration : "Vous êtes commerçant, prestataire de services, hôtelier, agent immobilier, ou professionnel indépendant ? Vous cherchez à digitaliser votre activité et trouver plus de clients ? Yukpo est fait pour vous."

Éléments Visuels :

  • Logo Yukpo apparaît rapidement (0:02)
  • Carrousel ultra-rapide (0.3s par image) montrant différents types de prestataires :
    • Commerçant dans son magasin
    • Prestataire de service (plombier, électricien)
    • Hôtelier
    • Agent immobilier
    • Développeur/service digital
    • Restaurateur
  • Texte animé : "Pour TOUS les prestataires"

Audio : Musique moderne et énergique (afrobeat léger). Voix off claire et directe. Rythme soutenu.

PARTIE 2 : AVANTAGES CLÉS (0:10 - 0:40)

0:10 - 0:25 Digitalisation Intelligente

Narration : "Avec Yukpo, digitalisez vos produits et services en 2 minutes. Prenez une photo, l'IA crée automatiquement votre fiche professionnelle. Plus besoin de passer des heures à créer des descriptions. L'application fait le travail pour vous."

Éléments Visuels :

  • Démonstration rapide : Photo d'un produit → Fiche créée automatiquement
  • Animation montrant le processus : Photo → IA analyse → Fiche complète
  • Texte animé : "2 minutes au lieu de 2 heures"
  • Interface Yukpo avec création intelligente en action

0:25 - 0:40 Recherche Multimodale & Géolocalisation

Narration : "Vos clients vous trouvent facilement. Recherche par image, par vidéo, ou par texte. Géolocalisation précise : seuls les clients près de chez vous voient vos offres. Plus de visibilité, plus de ventes."

Éléments Visuels :

  • Animation : Client prend photo → Résultats GPS apparaissent
  • Carte interactive montrant la géolocalisation
  • Liste de commerçants avec distances
  • Icônes : caméra, GPS, résultats
  • Texte animé : "Trouvé en 3 secondes"

PARTIE 3 : SERVICES SPÉCIALISÉS (0:40 - 0:55)

0:40 - 0:55 Plus qu'une Plateforme E-commerce

Narration : "Yukpo, c'est bien plus qu'une plateforme e-commerce. Transport, immobilier, santé, éducation, restauration : tout est intégré. Si vous offrez un service spécialisé, Yukpo a les outils adaptés à votre secteur."

Éléments Visuels :

  • Carrousel rapide des services spécialisés :
    • 🚗 Transport (taxis, bus, covoiturage)
    • 🏠 Immobilier (vente, location, visites virtuelles)
    • 🏥 Santé (rendez-vous, pharmacies, urgences)
    • 📚 Éducation (cours, formations)
    • 🍽️ Restauration (menus, réservations)
    • 🏨 Hôtellerie (réservations, meublés)
  • Animation montrant l'intégration de chaque service
  • Texte animé : "Une plateforme, tous les services"

PARTIE 4 : APPEL À L'ACTION (0:55 - 1:00)

0:55 - 1:00 Inscription Gratuite

Narration : "Inscrivez-vous maintenant, c'est 100% gratuit. Préparez vos produits et services avant le lancement officiel. Soyez prêt quand les clients arriveront. Yukpo - La révolution numérique africaine commence avec vous."

Éléments Visuels :

  • Logo Yukpo en grand format
  • Texte animé : "INSCRIPTION GRATUITE - PRÉ-LANCEMENT"
  • Bouton "S'inscrire maintenant" avec effet pulse
  • QR Code pour inscription rapide
  • Site web : www.yukpo.com/inscription
  • Fade out avec logo final

Audio : Musique finale énergique. Voix off déterminée. Fade out progressif.

SPÉCIFICATIONS TECHNIQUES

Durée Totale

60 secondes maximum

Résolution

1920x1080 (Full HD) minimum

Format

MP4 (H.264 ou H.265)

Frame Rate

30 fps (standard)

Rythme

Ultra-rapide et direct : Transitions de 0.2-0.3 seconde. Pas de temps mort. Chaque seconde compte.

Style Visuel

Moderne, professionnel, dynamique. Couleurs : Violet (#667EEA), Orange (#F39C12), Vert (#27AE60)

  • Le message doit être actionnable : inciter à l'inscription immédiate.
  • Adapter les exemples visuels selon les types de prestataires disponibles dans la région cible.
