## 💡 CAS D'USAGE CONCRETS

### Exemple 1 : Agricultrice vendant des tomates 🍅
```
Madame Ngono à Bafoussam vend ses tomates fraîches :
- Produit : Tomate fraîche locale
- Unité : Cagnon moyen (au lieu de devoir peser en kg)
- Quantité : 15 cagnons disponibles
- Prix : 1500 FCFA / cagnon (au lieu de 150 FCFA/kg)
- État : Ultra-frais (récolte ce matin)
- Vente : Au marché de Bafoussam, Prix négociable
```

### Exemple 2 : Éleveur vendant des œufs 🥚
```
Monsieur Kamdem à Yaoundé vend des œufs :
- Produit : Œufs de poule pondeuse
- Unité : Alvéole 30 œufs (au lieu de vendre à l'unité)
- Quantité : 100 alvéoles disponibles
- Prix : 2800 FCFA / alvéole
- État : Très frais (ponte d'hier)
- Livraison possible dans Yaoundé
```

### Exemple 3 : Producteur vendant du riz 🌾
```
Coopérative à Ndop vend du riz local :
- Produit : Riz blanc local
- Unité : Sac 50kg (au lieu de vendre au kg)
- Quantité : 200 sacs disponibles
- Prix : 25000 FCFA / sac (au lieu de 500 FCFA/kg)
- Qualité : Bio, Sans pesticides
- Vente en gros et demi-gros
```

### Exemple 4 : Éleveur vendant un mouton pour Tabaski 🐏
```
Éleveur au Sénégal vend des moutons :
- Produit : Mouton Djallonké (race locale)
- Unité : Tête (pas besoin de peser)
- Poids estimé : 30-35 kg
- Prix : 65000 FCFA / tête
- État : Vivant sur pied, Vacciné, Bonne santé
- Livraison possible à Dakar
```
