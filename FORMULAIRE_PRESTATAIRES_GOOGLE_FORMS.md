# 📋 Guide Formulaire Google Forms - Collecte Prestataires Yukpomnang

## 🎯 Description d'introduction (Section 1)

**Texte à copier dans la description du formulaire :**

```
Bienvenue sur la plateforme Yukpomnang ! 🚀

Nous recherchons des prestataires de livraison pour rejoindre notre réseau et offrir des services de livraison rapides et fiables à nos clients.

En remplissant ce formulaire, vous nous aidez à mieux comprendre votre profil et vos disponibilités. Vos informations seront utilisées uniquement pour vous contacter et évaluer votre candidature.

Le processus est simple et rapide (environ 5 minutes). Toutes les informations fournies restent confidentielles.

Merci de votre intérêt ! 🙏
```

---

## 📝 Structure du Formulaire

### **Section 1 : Informations Personnelles**

#### Question 1 : Nom complet *
- **Type** : Réponse courte
- **Texte** : "Quel est votre nom complet ?"
- **Validation** : Requis
- **Exemple** : "Jean Dupont"

#### Question 2 : Numéro de téléphone *
- **Type** : Réponse courte
- **Texte** : "Quel est votre numéro de téléphone ?"
- **Validation** : Requis
- **Format** : Format de validation - Numéro de téléphone
- **Exemple** : "+33 6 12 34 56 78"

#### Question 3 : Adresse email *
- **Type** : Réponse courte
- **Texte** : "Quel est votre adresse email ?"
- **Validation** : Requis
- **Format** : Format de validation - Email
- **Exemple** : "jean.dupont@example.com"

#### Question 4 : Adresse complète *
- **Type** : Réponse courte
- **Texte** : "Quelle est votre adresse complète (rue, ville, code postal) ?"
- **Validation** : Requis
- **Exemple** : "123 Rue de la République, 75001 Paris"

---

### **Section 2 : Localisation et Zone d'Intervention**

#### Question 5 : Ville principale d'intervention *
- **Type** : Réponse courte
- **Texte** : "Dans quelle ville souhaitez-vous principalement intervenir ?"
- **Validation** : Requis
- **Exemple** : "Paris", "Lyon", "Marseille"

#### Question 6 : Zones de livraison couvertes
- **Type** : Cases à cocher
- **Texte** : "Quelles zones géographiques pouvez-vous couvrir ? (Plusieurs choix possibles)"
- **Options** :
  - Centre-ville
  - Banlieue proche
  - Banlieue éloignée
  - Périphérie
  - Toute la région
- **Validation** : Au moins une option requise

#### Question 7 : Rayon d'intervention maximum
- **Type** : Choix multiples (une seule réponse)
- **Texte** : "Quel est votre rayon d'intervention maximum ?"
- **Options** :
  - Moins de 5 km
  - 5 à 10 km
  - 10 à 20 km
  - 20 à 50 km
  - Plus de 50 km
- **Validation** : Requis

---

### **Section 3 : Secteurs d'Activité et Services**

#### Question 8 : Type(s) de prestation *
- **Type** : Cases à cocher
- **Texte** : "Quels types de prestations souhaitez-vous proposer ? (Plusieurs choix possibles)"
- **Options** :
  - Livraison express (< 1h)
  - Livraison standard (2-4h)
  - Livraison programmée (24h+)
  - Livraison de colis fragiles
  - Livraison de documents
  - Livraison de denrées alimentaires (isotherme)
  - Livraison de colis volumineux
  - Autre (préciser dans la question suivante)
- **Validation** : Au moins une option requise

#### Question 9 : Autres services (optionnel)
- **Type** : Réponse courte
- **Texte** : "Si vous avez sélectionné "Autre" ou souhaitez préciser d'autres services, décrivez-les ici :"
- **Validation** : Optionnel

#### Question 10 : Types de colis acceptés *
- **Type** : Cases à cocher
- **Texte** : "Quels types de colis acceptez-vous de transporter ? (Plusieurs choix possibles)"
- **Options** :
  - Petits colis (< 5 kg)
  - Colis moyens (5-15 kg)
  - Colis lourds (15-30 kg)
  - Colis volumineux
  - Documents
  - Denrées alimentaires
  - Produits fragiles
  - Produits nécessitant une protection spéciale
- **Validation** : Au moins une option requise

---

### **Section 4 : Moyen de Transport et Équipements**

#### Question 11 : Type de véhicule/moyen de transport *
- **Type** : Choix multiples (une seule réponse)
- **Texte** : "Quel est votre moyen de transport principal ?"
- **Options** :
  - Vélo
  - Scooter / Moto
  - Voiture
  - Camionnette
  - À pied
  - Autre (préciser)
- **Validation** : Requis

#### Question 12 : Capacité de transport
- **Type** : Choix multiples (une seule réponse)
- **Texte** : "Quelle est la capacité maximale de transport de votre véhicule ?"
- **Options** :
  - Moins de 5 kg
  - 5 à 15 kg
  - 15 à 30 kg
  - 30 à 50 kg
  - Plus de 50 kg
- **Validation** : Requis

#### Question 13 : Équipements disponibles
- **Type** : Cases à cocher
- **Texte** : "Quels équipements avez-vous à disposition ? (Plusieurs choix possibles)"
- **Options** :
  - Caisse isotherme
  - Support pour colis volumineux
  - Boîte sécurisée
  - Protection pour documents
  - GPS intégré
  - Application de suivi
  - Autre équipement
- **Validation** : Optionnel

---

### **Section 5 : Disponibilité**

#### Question 14 : Jours de disponibilité *
- **Type** : Cases à cocher
- **Texte** : "Quels jours de la semaine êtes-vous disponible ? (Plusieurs choix possibles)"
- **Options** :
  - Lundi
  - Mardi
  - Mercredi
  - Jeudi
  - Vendredi
  - Samedi
  - Dimanche
- **Validation** : Au moins un jour requis

#### Question 15 : Créneaux horaires de disponibilité *
- **Type** : Cases à cocher
- **Texte** : "Quels sont vos créneaux horaires de disponibilité ? (Plusieurs choix possibles)"
- **Options** :
  - Matin (6h-12h)
  - Après-midi (12h-18h)
  - Soirée (18h-22h)
  - Nuit (22h-6h)
  - Disponible toute la journée
- **Validation** : Au moins un créneau requis

#### Question 16 : Disponibilité immédiate
- **Type** : Choix multiples (une seule réponse)
- **Texte** : "Êtes-vous disponible pour commencer immédiatement ?"
- **Options** :
  - Oui, disponible immédiatement
  - Oui, dans les 7 prochains jours
  - Oui, dans le mois
  - Non, plus tard (préciser dans la question suivante)
- **Validation** : Requis

#### Question 17 : Date de disponibilité (si applicable)
- **Type** : Date
- **Texte** : "Si vous n'êtes pas disponible immédiatement, à partir de quelle date le serez-vous ?"
- **Validation** : Optionnel (requis si "Non, plus tard" sélectionné)

---

### **Section 6 : Informations Complémentaires**

#### Question 18 : Expérience dans la livraison
- **Type** : Choix multiples (une seule réponse)
- **Texte** : "Avez-vous déjà de l'expérience dans la livraison ?"
- **Options** :
  - Oui, plus de 2 ans d'expérience
  - Oui, entre 6 mois et 2 ans
  - Oui, moins de 6 mois
  - Non, mais je suis motivé(e) pour apprendre
- **Validation** : Requis

#### Question 19 : Commentaires ou questions
- **Type** : Paragraphe
- **Texte** : "Avez-vous des commentaires, questions ou informations supplémentaires à nous communiquer ?"
- **Validation** : Optionnel

## ✅ Configuration Recommandée du Formulaire

### Paramètres généraux :
- ✅ **Collecter les adresses email** : Activé
- ✅ **Limiter à une seule réponse** : Activé (si nécessaire)
- ✅ **Afficher la barre de progression** : Activé
- ✅ **Shuffle question order** : Désactivé
- ✅ **Confirmation message** : Personnalisé

### Message de confirmation personnalisé :
```
Merci d'avoir rempli ce formulaire ! 🎉

Nous avons bien reçu votre candidature et allons l'examiner dans les plus brefs délais.

Vous recevrez une réponse par email dans les 48 heures.

En attendant, n'hésitez pas à nous contacter si vous avez des questions.

L'équipe Yukpomnang
```

### Paramètres de réponse :
- ✅ **Accepter les réponses** : Activé
- ✅ **Envoyer une copie des réponses par email** : Activé (optionnel)
- ✅ **Afficher les réponses résumées** : Activé

## 🔄 Intégration avec le Backend

### Mapping des données vers `CourierApplication` :

```rust
// Exemple de mapping depuis les réponses Google Forms
let profile_data = json!({
    "full_name": response["Nom complet"],
    "phone": response["Téléphone"],
    "email": response["Email"],
    "address": response["Adresse complète"],
    "city": response["Ville principale"],
    "zones": response["Zones couvertes"], // Array
    "max_radius_km": response["Rayon d'intervention"],
    "service_types": response["Types de prestation"], // Array
    "parcel_types": response["Types de colis acceptés"], // Array
    "vehicle_type": response["Type de véhicule"],
    "max_capacity_kg": response["Capacité de transport"],
    "equipments": response["Équipements"], // Array
    "availability_days": response["Jours de disponibilité"], // Array
    "availability_hours": response["Créneaux horaires"], // Array
    "available_from": response["Date de disponibilité"],
    "experience": response["Expérience"],
    "comments": response["Commentaires"]
});
```

## 📝 Notes Importantes

1. **Champs obligatoires** : Marquer avec un astérisque (*) dans le titre
2. **Validation** : Utiliser les validations intégrées de Google Forms
3. **Confidentialité** : Informer les prestataires sur l'utilisation des données
4. **RGPD** : Ajouter une case à cocher pour consentement RGPD si nécessaire
5. **Test** : Tester le formulaire avant publication
