**Développement Full-Stack : Une Transition Naturelle pour l'Ingénieur Statisticien**

En tant qu'Ingénieur Statisticien, j'ai toujours été passionné par la résolution de problèmes complexes et la transformation de données en solutions concrètes. Cette approche m'a naturellement conduit vers le développement d'applications informatiques, où je combine analyse de données, algorithmique et ingénierie logicielle.

**🚀 Mon Projet Actuel : Plateforme Multi-Services**

Je développe actuellement une application full-stack complète couvrant :
- **Backend Rust** : Architecture Axum/SQLx avec PostgreSQL (extensions pgvector pour recherche sémantique, imgsmlr pour similarité d'images). Plus de 100 contrôleurs API REST, services d'IA pour la génération de contenu, orchestration asynchrone, WebSocket pour la communication temps réel.
- **Mobile React Native/Expo** : Application cross-platform TypeScript avec 130+ écrans. Fonctionnalités avancées : géolocalisation temps réel, génération vidéo, réalité augmentée, WebRTC pour le streaming live, cartographie interactive.

**💡 Les Défis Techniques**

- Optimisation de requêtes SQL complexes avec index adaptatifs
- Gestion d'état globale dans une application mobile modulaire
- Intégration d'IA pour la recherche sémantique et la génération de contenu
- Architecture scalable avec Redis, MongoDB pour le cache et données non-relationnelles
- Pipeline vidéo avec Remotion pour la génération server-side

**🤖 Développement Assisté par IA**

J'utilise activement Cursor (assistant IA pour le code) pour accélérer mon développement. Cette approche me permet de :
- Comprendre rapidement des patterns complexes
- Générer du code boilerplate efficacement
- Maintenir la cohérence du code sur un grand codebase
- Apprendre les best practices des technologies modernes

**📊 La Synergie Statistique + Développement**

Mon background statistique m'aide à :
- Optimiser les algorithmes de recherche et de recommandation
- Analyser les performances et identifier les bottlenecks
- Implémenter des modèles prédictifs dans l'application
- Prendre des décisions data-driven pour l'architecture
