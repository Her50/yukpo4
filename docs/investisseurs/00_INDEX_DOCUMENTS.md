- **SAM** : $45 milliards

- **Croissance** : 15-20% CAGR

- **Utilisation** : 40% produit, 30% marketing, 15% équipe, 10% infra, 5% réserve

- **2029** : $85M (20+ pays)
- **2030** : $180M+ (Leader)

### ROI Investisseurs
- **Conservateur** : 10-15x sur 5 ans
- **Optimiste** : 20-30x sur 5 ans
- **Valorisation 2030** : $500M-$1B

### Métriques Clés
- **CAC** : <$8 (2026) → <$5 (2029)
- **LTV** : $80-$120
- **LTV/CAC** : >10x
- **Take Rate** : 11-13%
