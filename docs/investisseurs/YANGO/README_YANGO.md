## 🔄 CONVERSION DES DOCUMENTS

### Markdown → PDF

**Option 1 : Pandoc (Recommandé)**
```bash
pandoc ONE_PAGER_YANGO.md -o ONE_PAGER_YANGO.pdf
pandoc EXECUTIVE_SUMMARY_YANGO.md -o EXECUTIVE_SUMMARY_YANGO.pdf
pandoc FINANCIAL_SUMMARY_YANGO.md -o FINANCIAL_SUMMARY_YANGO.pdf
```

**Option 2 : Markdown → Word → PDF**
1. Ouvrir `.md` dans éditeur Markdown (Typora, Mark Text)
2. Exporter en Word (.docx)
3. Ouvrir Word et exporter en PDF

**Option 3 : En ligne**
- https://www.markdowntopdf.com/
- https://dillinger.io/ (exporter en PDF)

### HTML → PDF

**Option 1 : Navigateur**
1. Ouvrir `DEMANDE_FINANCEMENT_COMPLET_YANGO.html` dans navigateur
2. Fichier → Imprimer → Enregistrer en PDF

**Option 2 : Outils en ligne**
- https://www.ilovepdf.com/html-to-pdf
- https://html2pdf.com/
