## 📊 MÉTRIQUES ET KPIs

### Métriques d'Acquisition

- **CAC (Customer Acquisition Cost)** : <$8 (2026), <$7 (2027)
- **Taux d'adoption** : 15-20% croissance mensuelle
- **Sources trafic** : Répartition par canal
- **Taux de conversion** : Install → Inscription → Première transaction

### Métriques d'Engagement

- **DAU/MAU** : 40-50% (Daily Active Users / Monthly)
- **Sessions/mois** : 8-12 par utilisateur
- **Temps dans app** : 15-20 minutes/session
- **Taux de rétention** : 60% (30j), 40% (90j)

### Métriques Business

- **ARPU (Average Revenue Per User)** : $0.40-$0.50/mois
- **LTV (Lifetime Value)** : $80-$120
- **LTV/CAC Ratio** : >10x
- **Taux de conversion** : 15-25% (visiteurs → transactions)

### Métriques Brand

- **Brand Awareness** : 40% (2026), 60% (2027)
- **Net Promoter Score (NPS)** : >50
- **Satisfaction client** : >4.5/5
- **Mentions sociales** : Volume, sentiment
