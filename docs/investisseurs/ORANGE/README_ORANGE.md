## 📥 Comment utiliser le document

### Option 1 : Ouvrir directement dans Word
1. Double-cliquer sur `PORTEFEUILLE_INVESTISSEMENT_ORANGE.html`
2. Le fichier s'ouvre dans votre navigateur
3. **Fichier > Imprimer** (ou Ctrl+P)
4. Sélectionner "Enregistrer sous PDF" ou **Microsoft Print to PDF**
5. OU : Copier-coller le contenu dans Word et enregistrer

### Option 2 : Conversion en PDF directe
1. Ouvrir le fichier HTML dans un navigateur (Chrome, Edge, Firefox)
2. **Fichier > Imprimer** (Ctrl+P)
3. Destination : **"Enregistrer au format PDF"**
4. Paramètres recommandés :
   - Format : Lettre (21,59 x 27,94 cm) ou A4
   - Marges : Par défaut
   - Options : Arrière-plans graphiques activé
5. Cliquer sur "Enregistrer"

### Option 3 : Via Word (meilleure qualité)
1. Ouvrir Microsoft Word
2. **Fichier > Ouvrir** > Sélectionner `PORTEFEUILLE_INVESTISSEMENT_ORANGE.html`
3. Word convertira automatiquement le HTML en format Word
4. Vérifier la mise en forme (tableaux, couleurs)
5. **Fichier > Enregistrer sous > PDF** ou **Fichier > Exporter > Créer un document PDF**
