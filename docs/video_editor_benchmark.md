## Bench éditeur vidéo – TikTok / Reels / CapCut / Canva / Yukpo

### 1. Objectif
Documenter, de façon factuelle, les forces/faiblesses de Yukpo Studio par rapport aux éditeurs vidéo grand public (TikTok, Instagram Reels, CapCut, Canva) sur le plan **technique et UX de montage**, indépendamment de la popularité.

### 2. Scénario de référence
- **Tâche** : créer un montage simple à partir d’un service existant (3–5 scènes, texte, musique, CTA).  
- **Plateformes comparées** :  
  - TikTok  
  - Instagram Reels  
  - CapCut  
  - Canva Video  
  - Yukpo (web ImmersiveVideoWizard + CreatorStudio, mobile Expo)

Pour chaque plateforme, mesurer :
- Temps total pour aboutir à une première vidéo “publishable” (en secondes/minutes).  
- Nombre de gestes/clics principaux.  
- Nombre de points de friction (erreurs, latence, incompréhensions UI).

### 3. Grille d’analyse UX / technique

#### 3.1 Interactions “instantanées”
- Scrub (déplacement dans la vidéo) fluide.  
- Trim / cut de clips.  
- Ajout/retrait de clips dans la timeline.  
- Ajustement du texte (position, taille, couleur).  
- Changement de musique / volume.  
- Activation de filtres/effets.

#### 3.2 Fonctions avancées
- Auto‑beat sync (alignement sur la musique).  
- Auto‑sous‑titres.  
- Beautify / filtres visage.  
- Multi‑pistes (audio, vidéo, overlays).  
- Templates d’animation préréglés.  
- Aperçu temps réel vs rendu différé.

#### 3.3 Performances ressenties
- Délai moyen entre une modification (ex. déplacement d’un clip) et la mise à jour de l’aperçu.  
- Temps de prévisualisation complet (playback).  
- Temps de rendu final (export / upload).

### 4. Observations prévues pour Yukpo (à compléter)

#### 4.1 Forces
- Intégration profonde avec les **données métier** (services, produits, promos, delivery).  
- Assistant IA pour le brief et le storyboard.  
- Pipeline GPU serveur (Remotion) capable de gérer des rendus de qualité constante.  
- Analytics intégrés (PreviewMonitoring, video analytics).

#### 4.2 Gaps vs TikTok / Reels / CapCut / Canva
- Édition timeline moins “temps réel” (dépend du rendu serveur).  
- Peu ou pas de scrub interactif directement dans le navigateur/mobile.  
- Manque de manipulation directe des clips (drag & drop dans la vidéo elle‑même).  
- Fonctions avancées encore limitées (auto‑beat sync, effets très riches, stickers animés).

### 5. Plan de comblement (résumé)
- Bloc 0.2 / 0.3 : timeline web plus riche + aperçu rapide.  
- Bloc 0.4 : wizard mobile inspiré TikTok/Reels.  
- Bloc 0.5 : auto‑beat sync, effets texte/transitions, sous‑titres/stickers.  
- Bloc 0.6 : IA assistive qui exploite au maximum les spécificités Yukpo (données services/delivery/promo).
