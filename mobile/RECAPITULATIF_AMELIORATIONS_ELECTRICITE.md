## 11. 🎓 LOGIQUE MÉTIER

### Pourquoi cette Structure ?

**Produits électriques vs Services électriciens** :
- Avant : Orientation "services" (Installation, Réparation...)
- Après : Orientation "produits" (Ampoules, Câbles, Prises...)

**Catégories** :
- Regroupement logique : Câblage, Éclairage, Protection, Domotique...
- Facilite la recherche et le filtrage

**Champs Techniques** :
- **Tension** : Essentiel pour la compatibilité
- **Puissance** : Important pour dimensionnement
- **Culot** : Crucial pour ampoules
- **Normes** : Conformité et sécurité (IP44 = salle de bain, IP65 = extérieur)

**Couleur de Lumière** :
- Blanc chaud (2700K) : Ambiance chaleureuse
- Blanc neutre (4000K) : Bureaux, magasins
- Blanc froid (6000K) : Ateliers, garages
