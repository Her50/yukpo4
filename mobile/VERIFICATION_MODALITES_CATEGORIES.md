## 🆕 Nouvelle Catégorie Agroalimentaire

### Différenciation Claire

| Critère | Aliments Frais 🍎 | Agroalimentaire 🌾 |
|---------|-------------------|---------------------|
| **Nature** | Produits du marché | Produits transformés |
| **Conservation** | Court terme | Longue conservation |
| **Emballage** | Vrac/Naturel | Conditionné/Emballé |
| **Exemples** | Tomates fraîches, Poulet | Conserve tomates, Poulet fumé |
| **DLC** | Quelques jours | Plusieurs mois/ans |
| **Stockage** | Frais/Réfrigéré | Température ambiante |

### Mots-Clés Uniques

**Agroalimentaire** : riz, pâtes, farine, huile, conserve, sec, conditionné
**Aliments Frais** : frais, marché, viande, poisson, fruit, légume

### Exemples de Recherche

```
"riz basmati" → Agroalimentaire ✅
"tomate fraîche" → Aliments Frais ✅
"huile d'olive" → Agroalimentaire ✅
"poulet entier" → Aliments Frais ✅
"sardines en conserve" → Agroalimentaire ✅
"poisson frais" → Aliments Frais ✅
```
