# GUIDE D'AJOUT DE PHARMACIES RÉELLES

## ⚠️ IMPORTANT

Ce fichier contient actuellement des **localisations réelles** (quartiers, villes) mais **PAS des noms de pharmacies réelles**.

## 🎯 2 OPTIONS POUR OBTENIR DES NOMS RÉELS

### Option 1 : Utiliser uniquement des localisations (RECOMMANDÉ)
Garder les pharmacies génériques par quartier que l'utilisateur complètera avec le vrai nom.

### Option 2 : Ajouter les vrais noms manuellement
Vous devez fournir les vrais noms de pharmacies avec leurs adresses exactes.

## 📍 SOURCES POUR OBTENIR LES VRAIS NOMS

### Cameroun
- Association des pharmaciens du Cameroun
- Pages Jaunes Cameroun
- Google Maps (recherche "pharmacie [quartier]")

### Autres pays
- Annuaire officiel du pays
- Association des pharmaciens
- Google Maps avec localisation

## 💡 SOLUTION ACTUELLE

Les noms actuels sont des **identifiants de localisation** qui aideront les utilisateurs à identifier leur pharmacie :

```
✅ "Pharmacie Bonanjo (Douala)" → Localisation réelle
✅ "Pharmacie PK8 (Douala)" → Localisation réelle
❌ Nom exact de la pharmacie → À compléter par l'utilisateur
```

## ✅ PROCHAINES ÉTAPES

Choisir entre :
1. Garder les localisations uniquement (actualisé)
2. Fournir les vrais noms de pharmacies
