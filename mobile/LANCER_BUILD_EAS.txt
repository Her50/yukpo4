    🚀 LANCER UN BUILD EAS - YUKPOMNANG MOBILE - GUIDE RAPIDE
═══════════════════════════════════════════════════════════════

📌 MÉTHODE 1 : AVEC L'INTERFACE GRAPHIQUE (RECOMMANDÉ)
───────────────────────────────────────────────────────────────

Double-cliquez sur le fichier :
    ► BUILD-EAS.bat

Puis suivez le menu interactif !


📌 MÉTHODE 2 : EN LIGNE DE COMMANDE
───────────────────────────────────────────────────────────────

Ouvrez PowerShell dans le dossier mobile/ et exécutez :

1️⃣ VÉRIFIER LA CONFIGURATION
    powershell -ExecutionPolicy Bypass -File ./verif-eas.ps1

2️⃣ INSTALLER EAS CLI (si pas installé)
    npm install -g eas-cli

3️⃣ SE CONNECTER À EXPO
    eas login
    (utilisez le compte : hernandezlele)

4️⃣ INSTALLER LES DÉPENDANCES
    npm install

5️⃣ LANCER LE BUILD
    npm run build:preview

    OU

    npx eas build --platform android --profile preview


📌 MÉTHODE 3 : COMMANDE UNIQUE
───────────────────────────────────────────────────────────────

Si tout est déjà configuré :

    cd mobile
    npx eas build --platform android --profile preview


═══════════════════════════════════════════════════════════════
    ⏱️  DURÉE : 15-25 MINUTES
═══════════════════════════════════════════════════════════════

Le build se fera sur les serveurs Expo.
Vous recevrez un lien pour suivre la progression.
Une fois terminé, téléchargez l'APK et installez-le sur Android.

    🛠️  RÉPARER LE FONCTIONNEMENT LOCAL
═══════════════════════════════════════════════════════════════

Si l'app ne fonctionne plus en local (npm start) :

OPTION 1 : Nettoyage rapide
    npm run clean
    npm start

OPTION 2 : Nettoyage complet
    npm run clean:deep
    npm start

OPTION 3 : Réinstallation manuelle
    rm -rf node_modules .expo android ios
    npm install
    npm start
