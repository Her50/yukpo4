# 📱 Instructions : Ajouter l'Application Android dans Firebase

## 🎯 Vous êtes actuellement sur : Vue d'ensemble (Overview)

### ✅ ÉTAPE 3 : Ajouter l'Application Android

#### **Méthode 1 : Via le Menu Principal (Recommandé)**

1. **Regardez en haut de la page centrale** (à côté de "Bienvenue dans votre projet Firebase !")
2. **Cherchez un bouton ou une carte** qui dit :
   - "Ajouter une application" 
   - "Add an app"
   - Ou un bouton avec l'icône **🤖 Android** (robot Android)

3. **Si vous ne voyez pas directement**, regardez dans la **barre latérale gauche** :
   - Cliquez sur **"Créer"** (Build) dans la section "Catégories de produits"
   - Ou cherchez **"Project Settings"** (Paramètres du projet) - icône ⚙️ en haut à gauche

#### **Méthode 2 : Via Project Settings**

1. **Cliquez sur l'icône ⚙️ (engrenage)** en haut à gauche de la page
2. **Sélectionnez "Paramètres du projet"** ou **"Project Settings"**
3. **Descendez** jusqu'à la section **"Vos applications"** ou **"Your apps"**
4. **Vous verrez 3 icônes** :
   - 📱 **iOS** (iPhone)
   - 🤖 **Android** (robot)
   - 🌐 **Web** (globe)
5. **Cliquez sur l'icône 🤖 Android**

#### **Méthode 3 : Via le Menu Créer**

1. Dans la **barre latérale gauche**, cliquez sur **"Créer"** (Build)
2. Vous verrez les options :
   - Authentication
   - Firestore Database
   - Realtime Database
   - Storage
   - **Et en haut, un bouton pour ajouter une application**

---

## 📋 Une fois que vous avez cliqué sur Android :

Un formulaire s'ouvrira avec :

1. **Nom du package Android** (Android package name)
   - ⚠️ **ENTREZ EXACTEMENT** : `com.yukpomnang.mobile`
   - Pas d'espaces, pas de majuscules

2. **Surnom de l'application** (App nickname) - **OPTIONNEL**
   - Vous pouvez mettre : "Yukpomnang Mobile"

3. **Cliquez sur "Enregistrer l'application"** ou **"Register app"**

---

## 🔍 Si vous ne trouvez toujours pas :

### **Astuce : Regardez dans l'URL**
- L'URL actuelle est : `console.firebase.google.com/project/yukpomnang-93cb4/overview`
- Essayez d'aller directement sur : `console.firebase.google.com/project/yukpomnang-93cb4/settings/general`
- Puis descendez jusqu'à "Your apps" et cliquez sur l'icône Android

---

## ✅ Après avoir ajouté l'app Android :

1. Firebase vous proposera de **télécharger `google-services.json`**
2. **Cliquez sur "Télécharger google-services.json"**
3. Le fichier se téléchargera dans vos **Téléchargements**
4. Le script PowerShell détectera automatiquement le fichier et le copiera au bon endroit !
