**Patterns surveillés** :
- `Error|ERROR|Failed` → Erreurs critiques
- `TypeError|ReferenceError` → Erreurs JavaScript
- `Cannot read property` → Accès propriétés null
- `Cannot find module` → Modules manquants
- `undefined is not an object` → Objets undefined
- `Network request failed` → Échecs réseau
- `WARN|Warning` → Avertissements
