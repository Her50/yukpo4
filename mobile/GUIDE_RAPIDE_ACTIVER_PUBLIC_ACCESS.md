# ⚡ Guide Rapide : Activer l'Accès Public Wasabi

## 📖 Selon la documentation officielle Wasabi

Source : [Wasabi Documentation - Public Access Enable/Disable](https://docs.wasabi.com/docs/public-access-enabledisable)

## ✅ Étapes rapides

### 1. Aller dans Settings
- Cliquez sur votre bucket `yukpo-video-prod` dans la liste des buckets
- Cliquez sur **"Settings"** (onglet ou menu)

### 2. Ouvrir Public Access Override
- Dans le panneau **"Properties"**, ouvrez le menu déroulant **"Public Access Override"**

### 3. Activer l'accès public
- Glissez le slider vers **"Enable Public Access"**
- Cliquez sur **"OK"** pour confirmer

### 4. Ajouter la Bucket Policy
- Allez dans l'onglet **"Permissions"**
- Cliquez sur **"Edit"** dans "Bucket Policy"
- Collez le code JSON
- Sauvegardez

## ⚠️ IMPORTANT : Compte Trial

**ATTENTION** : Selon la documentation :
> "By default, public use of a bucket, folder, or file is allowed only by certain paid (not trial) accounts."

Vous avez un compte **Trial** (visible "Trial Ends in 12 days").

### Si l'option n'est pas disponible :
1. **Contactez Wasabi Support** : support@wasabi.com
2. Demandez d'activer l'accès public pour votre compte
3. Ou passez à un compte payant

## 🎯 Action immédiate

1. **Allez dans Settings** de votre bucket
2. **Ouvrez "Public Access Override"**
3. **Essayez d'activer "Enable Public Access"**
4. **Si ce n'est pas disponible** → Contactez Wasabi Support

Dites-moi si vous voyez l'option "Enable Public Access" dans Settings !
