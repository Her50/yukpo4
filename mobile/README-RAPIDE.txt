 COMMENT TESTER SUR VOTRE TELEPHONE
=====================================

ETAPE 1: Voir le QR Code
-------------------------
Ouvrez dans votre navigateur:
→ http://localhost:8081

Vous verrez le QR code a scanner.


ETAPE 2: Installer Expo Go
---------------------------
Sur votre telephone:
- Android: Play Store → "Expo Go"
- iOS: App Store → "Expo Go"


ETAPE 3: Scanner le QR Code
----------------------------
- Android: Ouvrez Expo Go → "Scan QR Code"
- iOS: Appareil photo → Scannez (ouvrira Expo Go)


ETAPE 4: L'app se charge!
--------------------------
L'application Yukpomnang va se charger automatiquement
sur votre telephone (10-30 secondes).
