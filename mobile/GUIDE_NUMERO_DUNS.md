# 📋 Guide : Obtenir un numéro D-U-N-S pour Google Play Console

## 🎯 Qu'est-ce qu'un numéro D-U-N-S ?

Le **D-U-N-S (Data Universal Numbering System)** est un identifiant unique à 9 chiffres attribué par **Dun & Bradstreet** pour identifier votre entreprise/organisation.

**⚠️ Important :**
- **Gratuit** à obtenir
- **Obligatoire** pour les comptes développeur Google Play d'organisation
- **Optionnel** pour les comptes développeur individuels (personne physique)

---

## ✅ Étape 1 : Vérifier si vous en avez besoin

### Compte Individuel (Personne physique)
- **Pas besoin** de D-U-N-S
- Utilisez votre nom personnel
- Plus simple et rapide

### Compte Organisation (Entreprise)
- **Besoin** d'un D-U-N-S
- Pour les entreprises, associations, organisations
- Plus professionnel mais plus complexe

**💡 Recommandation :** Si vous êtes seul ou une petite équipe, créez un **compte individuel** (plus simple, pas de D-U-N-S requis).

---

## 🔍 Étape 2 : Vérifier si votre organisation a déjà un D-U-N-S

**🔗 Lien direct :** https://www.dnb.com/duns-number/lookup.html

1. Allez sur : **https://www.dnb.com/duns-number/lookup.html**
2. Entrez le nom de votre entreprise
3. Sélectionnez votre pays
4. Cliquez sur **"Rechercher"** ou **"Search"**
5. Si trouvé, notez le numéro D-U-N-S (9 chiffres)

**Si votre entreprise existe déjà :** Utilisez ce numéro directement !

---

## 📝 Étape 3 : Demander un nouveau D-U-N-S (GRATUIT)

**🔗 Lien direct :** https://www.dnb.com/duns-number/get-a-duns-number.html

### 3.1 Accéder au formulaire

1. Allez sur : **https://www.dnb.com/duns-number/get-a-duns-number.html**
2. Cliquez sur **"Request a D-U-N-S Number"** ou **"Demander un numéro D-U-N-S"**
3. Sélectionnez votre pays

### 3.2 Remplir le formulaire

**Informations requises :**

1. **Informations de l'entreprise** :
   - Nom légal de l'entreprise (exactement comme enregistré)
   - Nom commercial (si différent)
   - Adresse complète (rue, ville, code postal, pays)
   - Numéro de téléphone
   - Email professionnel
   - Site web (si vous en avez un)

2. **Informations du contact** :
   - Prénom et nom
   - Titre/Fonction (ex: Directeur, Propriétaire)
   - Email
   - Téléphone

3. **Informations légales** :
   - Type d'entreprise (SARL, SAS, Auto-entrepreneur, etc.)
   - Date de création
   - Numéro SIRET (si vous êtes en France)
   - Nombre d'employés

4. **Informations financières** (optionnel mais recommandé) :
   - Chiffre d'affaires annuel
   - Secteur d'activité

### 3.3 Soumettre la demande

1. Vérifiez toutes les informations
2. Acceptez les conditions d'utilisation
3. Cliquez sur **"Soumettre"** ou **"Submit"**

### 3.4 Délai de traitement

- **Gratuit** : 5-7 jours ouvrables (parfois plus)
- **Payant (accéléré)** : 1-2 jours ouvrables (coût : ~50-200$ selon le pays)

**💡 Pour Google Play :** Le délai gratuit est généralement suffisant.

---

## 📧 Étape 4 : Vérifier votre email

1. **Email de confirmation** : Vous recevrez un email de Dun & Bradstreet confirmant votre demande
2. **Email avec le numéro** : Dans 5-7 jours, vous recevrez un email avec votre numéro D-U-N-S
3. **Vérification** : Dun & Bradstreet peut vous appeler pour vérifier les informations

---

## 🔢 Étape 5 : Utiliser le numéro D-U-N-S dans Google Play Console

Une fois que vous avez reçu votre numéro D-U-N-S :

1. Retournez sur **Google Play Console** : https://play.google.com/console
2. Dans le formulaire d'inscription, entrez votre numéro D-U-N-S (9 chiffres)
3. Google vérifiera automatiquement les informations
4. Si tout est correct, vous pourrez continuer

**⚠️ Important :**
- Le numéro doit correspondre exactement à votre entreprise
- Les informations doivent correspondre à celles de Google Play Console
- Vous avez un nombre limité de tentatives (généralement 3-5)

## 💡 Astuce : Compte Individuel vs Organisation

### Compte Individuel (Recommandé pour débuter)
✅ **Avantages :**
- Pas besoin de D-U-N-S
- Inscription plus rapide
- Moins de vérifications
- Idéal pour les développeurs indépendants

❌ **Inconvénients :**
- Nom personnel affiché publiquement
- Moins professionnel pour une entreprise

### Compte Organisation
✅ **Avantages :**
- Nom de l'entreprise affiché
- Plus professionnel
- Meilleur pour la crédibilité

❌ **Inconvénients :**
- Besoin d'un D-U-N-S
- Plus de vérifications
- Délai d'attente (5-7 jours)

---

## 🚀 Solution rapide : Utiliser un compte individuel

Si vous voulez publier rapidement sans attendre le D-U-N-S :

1. **Créez un compte individuel** dans Google Play Console
2. Utilisez votre nom personnel
3. Vous pouvez toujours créer un compte organisation plus tard
4. Transférez vos applications si nécessaire

**🔗 Lien pour compte individuel :** https://play.google.com/console/signup
