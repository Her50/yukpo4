# 💰 Tarification Wasabi - Résumé

### **Stockage** : 6,99 $ par téraoctet (To) par mois
- Soit environ **0,0068 $ par gigaoctet (Go) par mois**
- Environ **80% moins cher** qu'Amazon S3

### ✅ **Sans frais supplémentaires** :
- ❌ Pas de frais de sortie de données
- ❌ Pas de frais d'utilisation des API
- ❌ Pas de frais de requêtes
