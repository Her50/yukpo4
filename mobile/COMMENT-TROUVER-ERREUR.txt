  COMMENT TROUVER L'ERREUR DE CRASH
========================================

ÉTAPES:

1. Regardez la fenêtre PowerShell avec "npm start"
   (celle avec le QR code)

2. Scannez le QR code avec Expo Go

3. Quand l'app crash, l'erreur s'affiche en ROUGE
   dans cette fenêtre Metro

4. COPIEZ tout le texte de l'erreur

5. Envoyez-moi ce texte

ERROR  [quelque chose]

ou
TypeError: undefined is not an object...
ou
ReferenceError: xxx is not defined...

EXEMPLE D'ERREUR:

ERROR  Error: Unable to resolve module @react-navigation/native
at node_modules\...
etc.
