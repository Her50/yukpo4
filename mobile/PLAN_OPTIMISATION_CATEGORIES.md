## 🎯 Méthode d'Optimisation Standard

Pour chaque catégorie, suivre ces étapes :

### 1️⃣ **Analyse de l'Existant**
- Lire interface Product actuelle
- Lire formulaire actuel
- Lire affichage ProductCard actuel
- Identifier les gaps

### 2️⃣ **Enrichissement Interface Product**
- Ajouter champs manquants (10-20 champs selon catégorie)
- Types de champs : string, boolean, string[], number
- Commentaires clairs pour chaque champ

### 3️⃣ **Optimisation Formulaire**
- Organiser en 3-5 sections thématiques
- Utiliser `ProductFieldSelector` pour listes
- Créer `AutocompleteInput` si nécessaire (avec BD)
- Ajouter toggles, chips pour multiselect
- Champs conditionnels selon contexte

### 4️⃣ **Amélioration Affichage ProductCard**
- Badges colorés (statut, état, certifications)
- Identité claire (type + caractéristiques principales)
- Carte/Section pour infos clés
- Tags pour listes (équipements, services)
- Badges de confiance
- Styles CSS dédiés

### 5️⃣ **Optimisation Filtres**
- 8-15 filtres pertinents dans `categoryConfig.ts`
- Types : select, multiselect, range, toggle
- Logique de filtrage dans `ResultatBesoinScreen.tsx`
- Exclusion des filtres spéciaux de la logique générique

### 6️⃣ **CSV Import/Export**
- Template avec tous les nouveaux champs
- Exemples avec préfixe "Exemple"
- Parsing pour multiselect (split '|')
- Parsing pour boolean (toLowerCase === 'oui')

### 7️⃣ **Documentation**
- Créer fichier MD récapitulatif
- Avant/Après
- Guide d'utilisation
- Notes techniques
