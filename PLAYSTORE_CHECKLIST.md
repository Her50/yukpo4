# Checklist publication Play Store - Yukpo

## Étapes pré-publication

### 1. Configuration de l'application
- [ ] Nom de l'application : "Yukpo"
- [ ] Nom du package : com.yukpo.mobile (vérifier dans app.config.js)
- [ ] Icône de l'application (512x512 PNG)
- [ ] Captures d'écran (minimum 2, max 8)
  - [ ] Téléphone
  - [ ] Tablette (si applicable)

### 2. Contenu de la fiche Play Store
- [ ] Description courte (80 caractères max)
- [ ] Description complète (4000 caractères max)
- [ ] Catégorie : "Shopping" ou "Lifestyle"
- [ ] Tags pertinents
- [ ] Politique de confidentialité URL
- [ ] Site web de l'application

### 3. Configuration technique
- [ ] Niveau API cible : 33+ (requis par Google)
- [ ] Signature de l'application (release keystore)
- [ ] Mode de publication : Testing (pour les 12 testeurs)
- [ ] Configuration du test interne/fermé

### 4. Test avec 12 développeurs (14 jours)
- [ ] Créer une liste de testeurs fermée
- [ ] Ajouter les 12 emails des testeurs
- [ ] Générer le lien d'invitation
- [ ] Suivre l'utilisation quotidienne

### 5. Conformité Play Store
- [ ] Vérifier les permissions demandées
- [ ] Politique de confidentialité complète
- [ ] Mentions légales si nécessaire
- [ ] Conformité avec les règles de contenu

## Documents à préparer

### Politique de confidentialité
- URL vers votre page web
- Contenu : données collectées, usage, partage, suppression

### Captures d'écran requises
1. Écran d'accueil/dashboard
2. Écran de recherche de services
3. Écran de commande/demande
4. Écran de suivi de livraison
5. Écran de profil utilisateur
6. Écran de messagerie/chat

### Icônes et visuels
- Icône 512x512 PNG (fond transparent)
- Feature graphic (1024x500 JPG/PNG)
- Captures d'écran optimisées

## URLs importantes
- Play Console : https://play.google.com/console
- Documentation : https://developer.android.com/distribute
