## 🎯 MÉTHODE RAPIDE (3 clics)

### **Étape 1: Activer Cloud Translation API**

1. **Cliquez dans la barre de recherche** en haut de la page
   - Texte: "Tapez / pour rechercher des ressources, des documents, des produits, etc."
   
2. **Tapez exactement**: `Cloud Translation API`
   - Laisser apparaître les résultats

3. **Cliquez sur**: "Cloud Translation API" dans les résultats

4. **Cliquez sur le bouton bleu**: "ACTIVER" (en haut à droite)

✅ L'API est maintenant activée !

---

### **Étape 2: Ajouter à votre clé existante**

1. **Dans la barre de recherche**, tapez: `Credentials`

2. **Cliquez sur**: "APIs & Services" → "Credentials"

3. **Cliquez sur le nom de votre clé API** (celle que vous utilisez pour Maps)

4. **Dans la section "API restrictions"**:
   - Vérifiez que "Restrict key" est sélectionné
   - Dans la liste des APIs, vérifiez que "Cloud Translation API" est coché
   - Si ce n'est pas le cas, cliquez sur "Edit" et ajoutez-la

5. **Cliquez sur**: "ENREGISTRER" (Save) en bas

✅ Votre clé existante fonctionne maintenant pour Translate aussi !

---

## 📝 ALTERNATIVE: Créer une nouvelle clé

Si vous préférez une clé séparée :

1. **Dans Credentials**, cliquez sur **"+ CREATE CREDENTIALS"**

2. **Sélectionnez**: "API key"

3. **Nommez-la**: "Yukpomnang - Cloud Translation API"

4. **Configurez les restrictions**:
   - API restrictions: "Restrict key"
   - Cochez uniquement: "Cloud Translation API"

5. **Copiez la clé** qui s'affiche (⚠️ Notez-la maintenant !)

6. **Cliquez sur**: "ENREGISTRER" (Save)
