# 🔍 Comment Trouver votre Numéro de Client Hetzner

## 📋 Où Trouver le Numéro de Client

### Méthode 1 : Panel Hetzner Cloud (Recommandé)

1. **Connectez-vous au panel Hetzner** :
   - https://console.hetzner.cloud/
   - Connectez-vous avec vos identifiants

2. **Trouvez le numéro de client** :
   - Cliquez sur votre **nom d'utilisateur** (en haut à droite)
   - Allez dans **"Account Settings"** ou **"Profile"**
   - Le **Customer Number** (Numéro de client) est affiché dans cette section
   - Il ressemble généralement à : `1234567` ou `C1234567`

### Méthode 2 : Email de Bienvenue Hetzner

1. **Vérifiez votre email** (celui utilisé pour créer le compte Hetzner)
2. **Cherchez l'email** de Hetzner avec le sujet :
   - "Welcome to Hetzner Cloud"
   - "Your Hetzner Cloud account"
   - "Account created"
3. Le numéro de client est généralement mentionné dans cet email

### Méthode 3 : Factures Hetzner

1. **Dans le panel Hetzner** :
   - Allez dans **"Billing"** ou **"Invoices"**
   - Ouvrez une facture récente
   - Le numéro de client est affiché en haut de la facture
   - Format : `Customer Number: 1234567` ou `Kundennummer: 1234567`

### Méthode 4 : Support Hetzner

Si vous ne trouvez pas le numéro :
1. **Contactez le support Hetzner** :
   - https://console.hetzner.cloud/support
   - Ou par email : support@hetzner.com
2. **Fournissez** :
   - Votre email de compte
   - L'IP de votre serveur : `46.224.14.85`
   - Ils pourront vous donner votre numéro de client

## 📝 Informations Utiles pour Identifier votre Compte

Si vous avez besoin d'aide pour identifier votre compte :

- **IP du serveur** : `46.224.14.85`
- **Email de compte** : Celui utilisé pour créer le compte Hetzner
- **Nom du serveur** : Vérifiez dans le panel Hetzner

## 💡 Note

Le numéro de client Hetzner n'est généralement **pas nécessaire** pour :
- Se connecter au panel
- Réinitialiser le mot de passe root
- Utiliser l'API Hetzner Cloud (nécessite un token API, pas le numéro de client)

Il est principalement utile pour :
- Contacter le support
- Référencer votre compte dans les communications
- Vérifier votre identité
