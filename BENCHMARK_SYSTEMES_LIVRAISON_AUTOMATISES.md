## 🎯 SYSTÈMES EXISTANTS DANS LE MONDE

### **1. Plateformes de Livraison de Nourriture (Food Delivery)**

#### **Uber Eats** (2014, États-Unis)
**Comment ça marche** :
```
1. Client commande sur l'app
2. Uber Eats trouve automatiquement le restaurant
3. Algorithme de matching trouve le livreur le plus proche :
   - Distance au restaurant
   - Charge de travail actuelle du livreur
   - Temps de livraison estimé
   - Note du livreur
4. Livreur accepte ou refuse automatiquement
5. Tracking en temps réel jusqu'à la livraison
```

**Technologies** :
- ✅ Matching automatique en temps réel
- ✅ Optimisation des tournées
- ✅ GPS tracking en temps réel
- ✅ Système de rating (livreur/restaurant/client)

**Innovations** :
- Premier système à utiliser le réseau de chauffeurs Uber existant
- Matching ultra-rapide (< 1 minute)
- Système de "surge pricing" (prix dynamique selon la demande)

**Limitations** :
- ❌ Seulement nourriture/restaurants
- ❌ Nécessite infrastructure Uber (chauffeurs véhiculés)
- ❌ Pas adapté aux marchés avec beaucoup de motos

---

#### **DoorDash** (2013, États-Unis)
**Comment ça marche** :
```
1. Client commande → Algorithme trouve restaurant
2. Matching automatique avec livreur :
   - Distance au restaurant
   - Disponibilité
   - Score du livreur
3. Livreur reçoit notification
4. Tracking en temps réel
```

**Technologies** :
- ✅ Matching automatique multi-critères
- ✅ Optimisation des tournées groupées (plusieurs livraisons par livreur)
- ✅ Prédiction du temps de livraison (ML)

**Innovations** :
- Système de "Dasher" (livreurs indépendants)
- Optimisation des tournées groupées (plusieurs livraisons simultanées)
- Algorithme prédictif pour prévoir les pics de demande

**Limitations** :
- ❌ Principalement nourriture
- ❌ Concentré sur États-Unis/Canada
- ❌ Pas de support multi-modalités (moto/tricycle)

---

#### **Glovo** (2015, Espagne)
**Comment ça marche** :
```
1. Client commande (nourriture, courses, colis)
2. Matching automatique avec "Glover" (livreur)
3. Tracking en temps réel
4. Livraison multi-catégories
```

**Technologies** :
- ✅ Matching automatique multi-catégories
- ✅ Support plusieurs types de véhicules (moto, vélo, voiture)
- ✅ GPS tracking temps réel

**Innovations** :
- ✅ **Première plateforme à proposer livraison multi-catégories** (pas seulement nourriture)
- ✅ Support motos/vélos (adapté aux villes européennes/africaines)
- ✅ Expansion rapide en Afrique (Maroc, Kenya, etc.)

**Limitations** :
- ⚠️ Matching moins sophistiqué qu'Uber Eats
- ⚠️ Pas de système de zones logistiques avancé

---

#### **Deliveroo** (2013, Royaume-Uni)
**Comment ça marche** :
```
1. Client commande restaurant
2. Matching avec livreur (principalement vélo/moto en ville)
3. Tracking temps réel
```

**Technologies** :
- ✅ Matching automatique
- ✅ Optimisation pour vélos/motos (adapté villes européennes)
- ✅ Système de zones (zones de livraison définies)

**Innovations** :
- Focus sur vélo/moto (écologique, adapté centre-ville)
- Système de zones géographiques

**Limitations** :
- ❌ Seulement nourriture
- ❌ Principalement Europe

### **2. Plateformes Logistiques B2B (Enterprise)**

#### **Kardinal** (2015, France)
**Comment ça marche** :
```
1. Entreprise a besoin de livrer des colis
2. Kardinal optimise les tournées avec IA :
   - Combinaison recherche opérationnelle + Machine Learning
   - Adaptation en temps réel aux contraintes terrain
   - Optimisation selon trafic, météo, volumes variables
3. Génère plan de tournées optimal
4. Tracking des livraisons
```

**Technologies** :
- ✅ **IA + Recherche Opérationnelle** (algorithme hybride)
- ✅ Machine Learning pour prédictions
- ✅ Adaptation temps réel

**Innovations** :
- ✅ **Premier système à combiner IA + recherche opérationnelle**
- ✅ Adaptation automatique aux aléas (trafic, météo)
- ✅ Optimisation pour "dernier kilomètre" (logistique urbaine)

**Spécificité** :
- Plateforme **SaaS B2B** (pour entreprises, pas pour particuliers)
- Focus sur optimisation de tournées (pas matching client-livreur)

---

#### **Cainiao** (2013, Chine - Alibaba)
**Comment ça marche** :
```
1. Client commande sur Alibaba/Taobao
2. Cainiao gère toute la logistique :
   - Optimisation entrepôts
   - Matching automatique transporteurs
   - Routage intelligent
   - Livraison en 24h en Chine, 72h international
3. Tracking en temps réel
```

**Technologies** :
- ✅ IA pour prédiction de demande
- ✅ Optimisation entrepôts automatisée
- ✅ Matching multi-transporteurs
- ✅ Routage intelligent

**Innovations** :
- ✅ **Plus grand réseau logistique au monde** (200+ pays)
- ✅ Livraison ultra-rapide (24h en Chine)
- ✅ Intégration complète avec e-commerce Alibaba

**Spécificité** :
- Infrastructure massive (entrepôts, transporteurs, hubs)
- Pas accessible aux petites entreprises indépendantes

### **3. Plateformes Collaboratives (C2C)**

#### **Shopopop** (2016, France)
**Comment ça marche** :
```
1. Client commande courses
2. Particuliers (livreurs volontaires) proposent leurs trajets
3. Matching avec un particulier qui passe près du magasin
4. Le particulier livre en faisant son trajet habituel
```

**Technologies** :
- ✅ Matching géographique simple
- ✅ Système de rating

**Innovations** :
- ✅ **Modèle collaboratif** (particuliers, pas professionnels)
- ✅ Écologique (réutilisation trajets existants)
- ✅ Prix bas (partage coûts)

**Limitations** :
- ❌ Livraisons non garanties (dépend des volontaires)
- ❌ Pas de matching temps réel sophistiqué
- ❌ Principalement courses alimentaires

### **4. Livraisons par Drones**

#### **Zipline** (2014, États-Unis)
**Comment ça marche** :
```
1. Hôpital/clinique demande fourniture médicale urgente
2. Drone autonome décolle automatiquement
3. Livraison en moins d'1 heure dans rayon 100km
4. Tracking GPS en temps réel
```

**Technologies** :
- ✅ Drones autonomes
- ✅ Système de navigation GPS
- ✅ Décollage/atterrissage automatique

**Innovations** :
- ✅ **Livraison médicale ultra-rapide par drone**
- ✅ Drones en Côte d'Ivoire, Ghana, Rwanda (Afrique)
- ✅ Sauve des vies (sang, vaccins, médicaments urgents)

**Spécificité** :
- Cas d'usage spécifique (médical, zones rurales)
- Infrastructure coûteuse
- Pas pour livraisons générales

fn compute_candidate_score(candidate: &CourierMatchingCandidate, passenger_mode: bool) -> f64 {
    // 1. Composante Distance (60%)
    let distance_component = (1.0 - distance_ratio).max(-0.5);
    
    // 2. Composante Charge (20%)
    let load_component = 1.0 - load_factor.min(1.0);
    
    // 3. Composante Capacité (10%)
    let capacity_component = available_capacity / max_capacity;
    
    // 4. Bonus Primaire (10%)
    let primary_bonus = if candidate.is_primary { 0.1 } else { 0.0 };
    
    // 5. Bonus Poids (adaptatif)
    let weight_bonus = capacity_weight * 0.02;
    
    // 6. Mode Passager (innovation unique)
    if passenger_mode {
        let distance_bonus = distance_component * 0.2;
        let capacity_bonus = weight_bonus * 1.5;
        // Privilégier distance courte + capacité poids élevée

    // Score final pondéré
    distance_component * 0.6
        + load_component * 0.2
        + capacity_component * 0.1

        + weight_bonus
