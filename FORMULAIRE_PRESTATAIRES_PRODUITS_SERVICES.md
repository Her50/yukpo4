# 📋 Guide Formulaire Google Forms - Prestataires Produits & Services Yukpomnang

## 🎯 Description d'introduction (Section 1)

**Texte à copier dans la description du formulaire :**

```
Bienvenue sur la plateforme Yukpomnang ! 🚀

Vous êtes commerçant, artisan, professionnel ou entreprise et souhaitez proposer vos produits ou prestations de service sur notre plateforme ?

Ce formulaire nous permet de mieux comprendre votre activité, vos besoins et de vous accompagner dans votre intégration sur Yukpomnang.

Que vous vendiez des produits (vêtements, alimentation, électronique, immobilier, etc.) ou que vous proposiez des prestations de service (coiffure, déménagement, réparation, etc.), nous sommes là pour vous aider à développer votre activité en ligne.

Le formulaire prend environ 10 minutes à remplir. Toutes les informations fournies restent confidentielles et seront utilisées uniquement pour évaluer votre candidature et vous contacter.

Merci de votre confiance ! 🙏
```

## 📝 Structure du Formulaire

### **Section 1 : Informations Personnelles et Contact**

#### Question 1 : Nom complet *
- **Type** : Réponse courte
- **Texte** : "Quel est votre nom complet (ou nom du responsable) ?"
- **Validation** : Requis
- **Exemple** : "Jean Dupont" ou "Marie Martin"

#### Question 2 : Nom de l'entreprise/commerce (si applicable)
- **Type** : Réponse courte
- **Texte** : "Quel est le nom de votre entreprise, commerce ou établissement ?"
- **Validation** : Optionnel
- **Exemple** : "Boutique Mode & Style", "Salon de Coiffure Élégance"

#### Question 3 : Numéro de téléphone *
- **Type** : Réponse courte
- **Texte** : "Quel est votre numéro de téléphone principal ?"
- **Validation** : Requis
- **Format** : Format de validation - Numéro de téléphone
- **Exemple** : "+33 6 12 34 56 78" ou "+237 6 12 34 56 78"

#### Question 4 : Adresse email *
- **Type** : Réponse courte
- **Texte** : "Quel est votre adresse email professionnelle ?"
- **Validation** : Requis
- **Format** : Format de validation - Email
- **Exemple** : "contact@moncommerce.com"

#### Question 5 : Adresse complète du commerce/établissement *
- **Type** : Réponse courte
- **Texte** : "Quelle est l'adresse complète de votre commerce ou établissement ? (Rue, ville, code postal)"

## 📝 Notes Importantes

1. **Champs obligatoires** : Marquer avec un astérisque (*) dans le titre
2. **Validation** : Utiliser les validations intégrées de Google Forms
3. **Sections conditionnelles** : Utiliser la logique de saut de section pour afficher/masquer les sections produits/prestations selon le type d'activité
4. **Confidentialité** : Informer les prestataires sur l'utilisation des données
5. **RGPD** : Ajouter une case à cocher pour consentement RGPD si nécessaire
6. **Test** : Tester le formulaire avec différents scénarios avant publication

## 🎯 Workflow de Traitement Recommandé

1. **Réception** : Réponses automatiquement exportées vers Google Sheets
2. **Tri initial** : Filtrer par type d'activité, ville, secteur
3. **Contact** : Envoyer un email de confirmation dans les 24h
4. **Évaluation** : Examiner chaque candidature (48-72h)
5. **Onboarding** : Contacter les prestataires retenus pour l'intégration
6. **Suivi** : Créer un compte utilisateur avec `is_provider=true`
7. **Formation** : Proposer une session d'initiation à la plateforme
