# 🔧 Solution : Carte Non Cliquable

**Problème** : La carte "Places API (New)" n'est pas cliquable

---

## ✅ Solution 1 : Cliquer sur le Lien "Metrics"

**Action** : Cliquez sur le lien **"Metrics"** (l'icône de graphique en barres 📊) sur la carte "Places API (New)"

**Ce lien devrait vous amener aux métriques et quotas de l'API.**

---

## ✅ Solution 2 : URL Directe

**Copiez cette URL dans votre navigateur** :

```
https://console.cloud.google.com/apis/api/places-backend.googleapis.com/quotas?project=yukpomnang-460203
```

**OU** (si le projet ID est différent) :

```
https://console.cloud.google.com/apis/api/places-backend.googleapis.com/quotas?project=738929393617
```

Cela vous amènera **directement** à la page des quotas Places API.

---

## ✅ Solution 3 : Navigation via Menu

1. **Cliquez sur le menu hamburger** (☰) en haut à gauche
2. **Cherchez** "APIs & Services" ou "APIs et services"
3. **Cliquez** sur "APIs & Services"
4. **Cliquez** sur "Enabled APIs" ou "APIs activées"
5. **Cherchez** "Places API (New)" dans la liste
6. **Cliquez** sur "Places API (New)" dans la liste (pas la carte)
7. **Cliquez** sur l'onglet **"Quotas"**

---

## ✅ Solution 4 : Recherche dans la Console

1. **Cliquez sur la barre de recherche** en haut (ou appuyez sur `/`)
2. **Tapez** : `places api quotas`
3. **Sélectionnez** le résultat qui mène aux quotas Places API

---

## 🎯 Solution Recommandée

**Utilisez l'URL directe** (Solution 2) - c'est le plus rapide et le plus fiable :

```
https://console.cloud.google.com/apis/api/places-backend.googleapis.com/quotas?project=yukpomnang-460203
```

---

## ⚠️ Si Rien ne Fonctionne

Vérifiez :
1. **Permissions** : Vous devez avoir les droits pour voir/modifier les quotas
2. **Projet** : Assurez-vous d'être sur le bon projet (yukpomnang)
3. **Navigateur** : Essayez un autre navigateur ou rafraîchissez la page (F5)

---
