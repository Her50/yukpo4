# 🖱️ Où Cliquer pour Voir les Serveurs de Noms

## 🎯 Sur la Page Actuelle

### **Option 1 : Cliquer sur le Bouton Orange** (Le Plus Simple)

**Regardez en haut de la page**, à côté de `yukpomnang.com` :

Vous verrez un **bouton orange** avec une icône d'horloge qui dit :
```
🕐 Serveurs de noms invalides
```

**👉 Cliquez sur ce bouton orange** → Cela vous amènera directement à la section des serveurs de noms.

---

### **Option 2 : Aller dans DNS** (Alternative)

1. **Dans le menu de gauche**, cliquez sur **"DNS"**
2. **En haut de la page DNS**, vous verrez une section **"Serveurs de noms"** ou **"Nameservers"**
3. Les 2 serveurs seront affichés là

---

## 📋 Ce Que Vous Devriez Voir

Après avoir cliqué, vous verrez :

**Section "3. Remplacez vos serveurs de noms actuels"**

Avec les 2 serveurs Cloudflare :
- `isaac.ns.cloudflare.com` (avec bouton "Cliquez pour copier")
- `jillian.ns.cloudflare.com` (avec bouton "Cliquez pour copier")

---

## ✅ Action Rapide

1. **Cliquez sur le bouton orange** "Serveurs de noms invalides"
2. **Copiez les 2 serveurs** (ou notez-les)
3. **Allez dans Namecheap** pour les mettre à jour
