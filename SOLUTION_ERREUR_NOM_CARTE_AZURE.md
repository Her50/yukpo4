# 🔧 Solution : Erreur Nom de Carte Azure

**Date** : 2026-02-14  
**Problème** : Le nom "LELE Hernandez" est rejeté lors de l'inscription Azure

---

## ⚠️ PROBLÈME DÉTECTÉ

Le formulaire Azure affiche une erreur :
- **Nom saisi** : "LELE Hernandez"
- **Erreur** : "Vérifiez que les informations de tous les champs sont correctes ou essayez une autre carte"

---

## ✅ SOLUTIONS À ESSAYER

### Solution 1 : Format du Nom (Recommandé)

**Essayer ces variantes** :

1. **Nom complet en majuscules** :
   ```
   LELE HERNANDEZ
   ```

2. **Prénom puis Nom** :
   ```
   LELE HERNANDEZ
   ```

3. **Sans espaces multiples** :
   ```
   LELE HERNANDEZ
   ```
   (Vérifier qu'il n'y a pas d'espaces en trop)

4. **Avec prénom complet si disponible** :
   ```
   [PRENOM COMPLET] HERNANDEZ
   ```

---

### Solution 2 : Vérifier le Nom Exact sur la Carte

**Le nom sur la carte doit correspondre EXACTEMENT** :
- ✅ Vérifier la carte physique
- ✅ Le nom doit être **exactement** comme sur la carte
- ✅ Respecter les majuscules/minuscules
- ✅ Respecter les accents (si présents)

**Exemples de formats possibles** :
- `LELE HERNANDEZ`
- `L. HERNANDEZ`
- `LELE H.`
- `HERNANDEZ LELE`

---

### Solution 3 : Problèmes Courants

**Vérifier** :
1. ✅ **Pas d'espaces en début/fin** : " LELE Hernandez " → "LELE Hernandez"
2. ✅ **Pas de caractères spéciaux** : Pas de `-`, `'`, etc. sauf si sur la carte
3. ✅ **Longueur** : Maximum 50 caractères
4. ✅ **Format** : Prénom + Nom (séparés par un espace)

---

### Solution 4 : Utiliser un Autre Navigateur

**Parfois le problème vient du navigateur** :
- ✅ Essayer **Chrome** (recommandé)
- ✅ Essayer **Edge**
- ✅ Essayer **Firefox**
- ✅ Désactiver les extensions (AdBlock, etc.)

---

### Solution 5 : Vérifier les Autres Champs

**Vérifier que tous les champs sont corrects** :
- ✅ **Numéro de carte** : 4455381412602878
- ✅ **Date d'expiration** : 02/27
- ✅ **CVV** : 180
- ✅ **Nom** : Format exact de la carte

**Si un champ est incorrect, l'erreur peut apparaître sur le nom**.

---

### Solution 6 : Contacter le Support Azure

**Si rien ne fonctionne** :
1. Aller sur https://azure.microsoft.com/fr-fr/support/options/
2. Cliquer sur **"Créer une demande de support"**
3. Sélectionner **"Facturation"** comme type de problème
4. Décrire le problème avec le nom de la carte

---

## 🔍 VÉRIFICATION RAPIDE

**Checklist** :
- [ ] Nom exactement comme sur la carte physique
- [ ] Pas d'espaces en trop
- [ ] Format : Prénom + Nom
- [ ] Tous les autres champs corrects
- [ ] Navigateur à jour
- [ ] Extensions désactivées

---

## 💡 ASTUCE

**Si vous avez plusieurs cartes** :
- Essayer avec une autre carte Visa
- Ou utiliser une Mastercard/Amex si disponible
