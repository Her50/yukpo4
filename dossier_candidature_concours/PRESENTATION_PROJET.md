## 🎨 CONSEILS POUR LA PRÉSENTATION

### Design Visuel

**Couleurs** :
- **Principal** : Bleu/Violet moderne (#6366F1)
- **Accent** : Orange/Verte (#F59E0B, #10B981)
- **Fond** : Blanc/Gris clair

**Typographie** :
- **Titres** : Bold, grande taille (36-48pt)
- **Corps** : Lisible (18-24pt)
- **Police** : Sans-serif moderne (Inter, Roboto)

**Images** :
- **Screenshots** : Application mobile en contexte
- **Graphiques** : Couleurs vives, légendes claires
- **Photos** : Marché africain, utilisateurs réels

### Timing

**Répartition 10 Minutes** :
- Introduction (Slide 1-2) : 1.5 min
- Solution (Slide 3-4) : 2.5 min
- État/Marché (Slide 5-6) : 2.5 min
- Business (Slide 7-8) : 3 min
- Financement/CTA (Slide 9-12) : 2.5 min

**Règle** : 1 slide = 1 minute maximum

### Techniques de Présentation

**Ouverture** :
- Question accrocheuse : "Combien d'applications utilisez-vous pour trouver un service local ?"
- Statistique choc : "60-80% de l'économie africaine est informelle"

**Milieu** :
- Démo vidéo : Création produit en temps réel (30 secondes)
- Témoignage : Utilisateur réel (si disponible)

**Fermeture** :
- Vision inspirante : "L'Afrique connectée"
- Call-to-action clair : "Rejoignez-nous"

### Points d'Attention

**À Éviter** :
- ❌ Trop de texte par slide (max 5-6 points)
- ❌ Graphiques complexes
- ❌ Détails techniques excessifs
- ❌ Dérive sur le timing

**À Faire** :
- ✅ Messages clairs et concis
- ✅ Visuels impactants
- ✅ Storytelling (problème → solution → succès)
- ✅ Pratiquer le timing
