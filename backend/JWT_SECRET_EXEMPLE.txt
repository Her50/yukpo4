# 🔑 JWT_SECRET - Clé Prête à l'Emploi

## ⚠️ IMPORTANT
Cette clé est un EXEMPLE. Pour la production, générez VOTRE PROPRE clé unique!

## Clé Exemple (64 caractères hexadécimaux)

JWT_SECRET=7a9f3c8d2e1b4f6a8c0d2e4f6a8b0c2d4e6f8a0b2c4d6e8f0a2b4c6d8e0f2a4b6

---

## Comment Utiliser

### Option 1: Utiliser le script PowerShell

```powershell
cd backend
.\generate-jwt-secret.ps1
```

Le script générera une clé unique et la copiera dans le presse-papiers.

---

### Option 2: Générer manuellement avec PowerShell

Copiez et collez cette commande dans PowerShell:

```powershell
$bytes = New-Object byte[] 32; $rng = [System.Security.Cryptography.RandomNumberGenerator]::Create(); $rng.GetBytes($bytes); -join ($bytes | ForEach-Object { $_.ToString("x2") })
```

---

### Option 3: Utiliser un générateur en ligne

1. Allez sur: https://generate-secret.vercel.app/64
2. Cliquez sur "Generate"
3. Copiez la clé générée
4. Ajoutez-la dans votre .env: `JWT_SECRET=votre_cle_generee`

---

## Configuration dans .env

Ajoutez cette ligne dans votre fichier `backend/.env`:

```bash
JWT_SECRET=7a9f3c8d2e1b4f6a8c0d2e4f6a8b0c2d4e6f8a0b2c4d6e8f0a2b4c6d8e0f2a4b6
```

**⚠️ REMPLACEZ cette clé par votre propre clé unique avant la production!**
