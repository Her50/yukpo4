# ⚖️ RÉALITÉ JURIDIQUE CAMEROUN : Levée de Fonds & Contrôle

## 🎯 LA VÉRITÉ SUR LE DROIT OHADA (Important!)

### Qu'est-ce que le Droit OHADA ?

**OHADA** = Organisation pour l'Harmonisation en Afrique du Droit des Affaires

**Pays concernés** : 17 pays dont Cameroun, Gabon, Congo, Côte d'Ivoire, Sénégal, etc.

**Principe** : Loi UNIFORME sur les sociétés commerciales (impossible de faire "à l'américaine" directement)

---

## ⚠️ CE QUI N'EST PAS POSSIBLE AU CAMEROUN (Soyons honnêtes)

### Dual-Class Shares "à l'Américaine" = NON ❌

```
IMPOSSIBLE SOUS OHADA :
───────────────────────

❌ Actions Classe B avec 10 votes/action (style Google)
❌ Actions super-votes comme aux USA
❌ Structure juridique identique Silicon Valley

POURQUOI ?
──────────
L'Acte Uniforme OHADA sur les sociétés commerciales 
ne prévoit PAS explicitement les actions à votes multiples 
de type "1 action = 10 votes".

Article 778 OHADA :
"Chaque action donne droit à une voix"

= En théorie, 1 action = 1 vote seulement
```

**MAIS ATTENDEZ !** Ce n'est PAS la fin du monde ! 🙂

## ✅ CE QUI EST POSSIBLE AU CAMEROUN (Solutions Réelles)

### Solution 1 : ACTIONS PRÉFÉRENTIELLES SANS DROIT DE VOTE

**Principe** : Les investisseurs reçoivent actions SANS droit de vote (légal OHADA!)

```
STRUCTURE LÉGALE OHADA
──────────────────────

Capital social : 1,000 actions

ACTIONS ORDINAIRES (Avec vote) :
├─ Nombre : 700 actions
├─ Détenteur : VOUS (fondateur)
├─ Droits : 1 vote/action + dividendes
└─ Total votes : 700 (100% des votes !)

ACTIONS PRÉFÉRENTIELLES (SANS vote) :
├─ Nombre : 300 actions
├─ Détenteur : INVESTISSEURS
├─ Droits : 0 vote mais dividendes prioritaires
└─ Total votes : 0

RÉSULTAT :
Capital : Vous 70%, Investisseurs 30%
Votes : Vous 100% ✅✅✅

COMPENSATIONS INVESTISSEURS (Pour accepter 0 vote) :
✅ Dividendes prioritaires (payés avant vous)
✅ Liquidation préférentielle (récupèrent capital en premier)
✅ Taux dividende fixe (ex: 8%/an garanti)
✅ Droit conversion en actions ordinaires (option future)
```

**Article OHADA autorisant ceci** :

```
Acte Uniforme OHADA Article 779 :
"Des actions de priorité peuvent être créées avec ou 
sans droit de vote."

Article 780 :
"Les actions de priorité peuvent bénéficier d'avantages 
par rapport aux actions ordinaires, notamment :
- Dividende prioritaire
- Attribution prioritaire en cas de liquidation
- Droit de rachat"

= C'EST LÉGAL ! ✅
```

**COMMENT METTRE ÇA EN PLACE CONCRÈTEMENT ?**

```
DANS LES STATUTS (Rédigé par avocat) :

"Article X - Capital Social

Le capital social est fixé à 300,000,000 FCFA, 
divisé en 1,000 actions de 300,000 FCFA chacune :

- 700 ACTIONS ORDINAIRES
  └─ Droits : 1 vote/action + dividendes
  
- 300 ACTIONS PRÉFÉRENTIELLES SÉRIE A
  └─ Droits : 0 vote + dividendes prioritaires
  
  Avantages actions préférentielles :
  a) Dividende annuel garanti : 8% de la valeur nominale
  b) Priorité de paiement (avant actions ordinaires)
  c) Liquidation préférentielle : 1x montant investi
  d) Option de conversion en actions ordinaires 
     après 5 ans (ratio 1:1)

Les actions préférentielles sont souscrites par 
les investisseurs en numéraire.

Émission initiale :
- 700 actions ordinaires → Fondateur
- 300 actions préférentielles → Investisseurs Série A"

SIGNATURES :
├─ Vous (Fondateur)
├─ Investisseurs
├─ Notaire
└─ Enregistrement RCCM
```

**EST-CE QUE ÇA PASSE VRAIMENT ?**

✅ **OUI ! C'est la méthode STANDARD au Cameroun pour levées de fonds**

**Exemples concrets Cameroun** :
- Plusieurs startups camerounaises utilisent déjà ce système
- Accepté par RCCM (Registre Commerce)
- Validé par jurisprudence OHADA
- Investisseurs africains connaissent bien ce mécanisme

CLAUSE 2 : CONSEIL D'ADMINISTRATION
────────────────────────────────────
"Composition du Conseil :

ADMINISTRATEURS FONDATEURS : 3 sièges
├─ [Votre Nom] (Président du Conseil)
├─ [CTO/Co-fondateur]

a) Faute grave (fraude, détournement, condamnation)
   ET

   ET
c) Procédure contradictoire (droit défense)

En cas révocation, indemnités :
- 24 mois salaire brut
- Conservation actions avec droits préférentiels
- Non-concurrence levée

Cette clause est d'ordre public entre actionnaires."

= IMPOSSIBLE VOUS VIRER sauf faute très grave ✅


CLAUSE 4 : CESSION D'ACTIONS (Inaliénabilité)

"Actions du Fondateur sont INALIÉNABLES pendant 5 ans

- Inaliénables 2 ans (lock-up)
- Après 2 ans : Droit de préemption Fondateur
  (Fondateur peut racheter avant vente à tiers)

Tag-along : Si investisseur vend, fondateur peut suivre
Drag-along : Si fondateur reçoit offre > 25 Mrd FCFA,
              peut forcer investisseurs à vendre"

= VOUS CONTRÔLEZ qui entre au capital ✅


CLAUSE 5 : ANTI-DILUTION
─────────────────────────
"En cas de levées futures, Fondateur bénéficie :

a) Droit de souscription préférentiel
   (Acheter actions nouvelles pour maintenir %)
   
b) Si down-round (valorisation baisse) :
   Ajustement prix pour protéger Fondateur
   
c) Garantie participation minimale :
   Fondateur conserve minimum 25% capital
   même après toutes dilutions futures

Cette garantie est prioritaire sur tout autre droit."

= PROTECTION long-terme ✅
