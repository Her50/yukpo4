# 🔗 Lien AWS : Méthodes de Paiement

**Date** : 2026-02-14  
**Objectif** : Voir les informations de votre carte Visa enregistrée dans AWS

---

## 🔗 LIEN DIRECT

**Page de gestion des méthodes de paiement AWS** :
```
https://console.aws.amazon.com/billing/home#/paymentmethods
```

**Ou via le menu** :
1. Aller sur https://console.aws.amazon.com
2. Cliquer sur votre nom en haut à droite
3. Sélectionner **"Billing & Cost Management"** (Facturation et gestion des coûts)
4. Dans le menu de gauche, cliquer sur **"Payment methods"** (Méthodes de paiement)

---

## 📋 INFORMATIONS VISIBLES

Sur cette page, vous pouvez voir :
- ✅ **Type de carte** : Visa, Mastercard, etc.
- ✅ **4 derniers chiffres** de la carte
- ✅ **Date d'expiration**
- ✅ **Nom sur la carte** (si enregistré)
- ✅ **Adresse de facturation**

---

## ⚠️ NOTE IMPORTANTE

**AWS et Azure sont des services séparés** :
- Les informations de paiement AWS ne sont **pas** automatiquement transférées vers Azure
- Vous devrez **créer un nouveau compte Azure** et enregistrer votre carte

---

## 🔄 POUR CRÉER UN ABONNEMENT AZURE

**Utiliser les mêmes informations de carte** :
1. Aller sur https://azure.microsoft.com/fr-fr/free/
2. Cliquer sur **"Démarrer gratuitement"**
3. Utiliser les **mêmes informations de carte** que dans AWS
4. Créer l'abonnement Azure
