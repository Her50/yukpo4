# 📞 Guide : Contacter AWS pour Problème de Facturation

**Date** : 2026-02-14  
**Problème** : Facture de plus de 600$ sur un compte de test

---

## 🎯 SITUATION

- **Premier compte AWS** : Facture de 600$+
- **Contexte** : Test de l'application, pas de maîtrise des coûts
- **Objectif** : Résoudre la facturation ou créer un nouveau compte

---

## ✅ OPTION 1 : Contacter AWS Support (Recommandé)

### Lien Direct Support AWS

**Page de support AWS** :
```
https://console.aws.amazon.com/support/home
```

**Ou via le menu** :
1. Aller sur https://console.aws.amazon.com
2. Cliquer sur **"Support"** en haut à droite
3. Sélectionner **"Support Center"**

---

### Créer une Demande de Support

**Étapes** :
1. Cliquer sur **"Create case"** (Créer une demande)
2. **Type de problème** : Sélectionner **"Account and billing support"** (Support compte et facturation)
3. **Catégorie** : Sélectionner **"Billing"** (Facturation)
4. **Service** : Sélectionner **"Account"** (Compte)

---

### Message à Envoyer (Modèle)

**Sujet** :
```
Demande d'annulation de facture - Compte de test sans maîtrise des coûts
```

**Message** (en français ou anglais) :
```
Bonjour,

Je contacte AWS concernant une facture importante sur mon compte AWS.

Contexte :
- J'ai créé ce compte AWS pour tester une application
- Je n'avais pas la maîtrise des coûts et des services utilisés
- La facture s'élève à plus de 600$ alors que je testais seulement l'application
- Je n'ai pas les moyens de payer cette facture

Demande :
- Pouvez-vous examiner cette facture et voir si une réduction ou annulation est possible ?
- Je suis prêt à fournir des explications supplémentaires si nécessaire

Je comprends que j'aurais dû mieux surveiller mes coûts, mais j'étais en phase de test et j'ai mal configuré les services.

Merci de votre compréhension.

Cordialement,
[Votre nom]
```

---

### Informations à Fournir

**AWS peut demander** :
- ✅ Numéro de compte AWS
- ✅ Numéro de facture
- ✅ Explication détaillée de l'utilisation
- ✅ Preuve que c'était un compte de test

---

## ⚠️ OPTION 2 : Créer un Nouveau Compte AWS

### Ce qu'AWS Vérifie

**AWS vérifie plusieurs éléments** :
1. ✅ **Email** : Doit être différent
2. ✅ **Carte de crédit** : Doit être différente OU même carte mais compte différent
3. ✅ **Adresse IP** : ⚠️ **OUI, AWS vérifie l'IP**
4. ✅ **Adresse de facturation** : Doit être différente
5. ✅ **Numéro de téléphone** : Doit être différent
6. ✅ **Nom** : Peut être le même

---

### Risques de Créer un Nouveau Compte

**⚠️ ATTENTION** :
- AWS peut **détecter** le lien entre les comptes (IP, carte, etc.)
- Si le premier compte a une **facture impayée**, AWS peut :
  - **Bloquer** le nouveau compte
  - **Demander le paiement** avant activation
  - **Suspendre** les deux comptes

---

### Si Vous Créez un Nouveau Compte

**Pour minimiser les risques** :
1. ✅ **Email complètement différent** (nouveau domaine si possible)
2. ✅ **Carte de crédit différente** (ou prépayée)
3. ✅ **Adresse IP différente** :
   - Utiliser un VPN
   - Utiliser un autre réseau (mobile, café, etc.)
4. ✅ **Adresse de facturation différente**
5. ✅ **Numéro de téléphone différent**
6. ✅ **Nom différent** (si possible)

**⚠️ Même avec tout ça, AWS peut détecter le lien !**

---

## 💡 RECOMMANDATION

### Option A : Contacter AWS d'abord (Meilleure Option)

**Avantages** :
- ✅ AWS peut **annuler ou réduire** la facture
- ✅ Pas de risque de suspension de compte
- ✅ Solution légale et propre

**Inconvénients** :
- ⏱️ Peut prendre du temps (quelques jours)
- ⚠️ Pas garanti que AWS accepte

---

### Option B : Créer un Nouveau Compte (Risqué)

**Avantages** :
- ✅ Compte "propre" pour repartir
- ✅ Pas de facture impayée

**Inconvénients** :
- ⚠️ Risque de détection par AWS
- ⚠️ Risque de suspension des deux comptes
- ⚠️ Violation possible des conditions d'utilisation

---

## 📋 PLAN D'ACTION RECOMMANDÉ

### Étape 1 : Contacter AWS Support (Aujourd'hui)

1. Aller sur https://console.aws.amazon.com/support/home
2. Créer une demande de support (modèle ci-dessus)
3. Attendre la réponse (24-48h généralement)

### Étape 2 : En Attendant la Réponse

1. **Ne pas créer de nouveau compte** (risque de suspension)
2. **Ne pas utiliser** le compte actuel (pour éviter d'augmenter la facture)
3. **Documenter** l'utilisation (logs, services utilisés)

### Étape 3 : Selon la Réponse AWS

**Si AWS accepte de réduire/annuler** :
- ✅ Résoudre le problème avec AWS
- ✅ Continuer avec le compte actuel ou créer un nouveau compte proprement

**Si AWS refuse** :
- ⚠️ Évaluer les options (paiement, nouveau compte avec VPN, etc.)
