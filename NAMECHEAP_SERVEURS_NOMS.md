# 🖱️ Namecheap : Où Cliquer pour Modifier les Serveurs de Noms

## 🎯 Sur la Page Actuelle

### **Vous êtes au bon endroit !**

Sur la page, vous voyez une section qui dit :
```
SERVEURS DE NOMS
```

En dessous, il y a un **menu déroulant** qui affiche :
```
Namecheap BasicDNS ▼
```

---

## 📋 Étapes Détaillées

### **Étape 1 : Cliquer sur le Menu Déroulant**

1. **Regardez la section "SERVEURS DE NOMS"**
2. **Vous verrez un menu déroulant** avec "Namecheap BasicDNS"
3. **👉 Cliquez sur ce menu déroulant** (sur la flèche ▼ ou sur le texte)

---

### **Étape 2 : Sélectionner "Custom nameservers"**

Après avoir cliqué sur le menu déroulant, vous verrez des options :
- Namecheap BasicDNS
- **Custom nameservers** ← **Sélectionnez celui-ci**

---

### **Étape 3 : Entrer les Serveurs Cloudflare**

Après avoir sélectionné "Custom nameservers", 2 champs apparaîtront :

**Champ 1** : Entrez
```
isaac.ns.cloudflare.com
```

**Champ 2** : Entrez
```
jillian.ns.cloudflare.com
```

---

### **Étape 4 : Sauvegarder**

1. **Cliquez sur le bouton "Sauvegarder"** ou "Save"
2. **Confirmez** si demandé
