# 📝 Modèle : Message pour AWS Support

**Date** : 2026-02-14  
**Usage** : Message à envoyer à AWS Support pour problème de facturation

---

## 🇫🇷 VERSION FRANÇAISE

**Sujet** :
```
Demande d'annulation/réduction de facture - Compte de test
```

**Message** :
```
Bonjour,

Je contacte AWS concernant une facture importante sur mon compte AWS [NUMÉRO DE COMPTE].

Contexte :
- J'ai créé ce compte AWS pour tester une application en développement
- Je n'avais pas la maîtrise des coûts et des services utilisés
- La facture s'élève à plus de 600$ alors que je testais seulement l'application
- Je n'ai pas les moyens de payer cette facture
- Je n'étais pas au courant des coûts réels des services utilisés

Détails :
- Numéro de compte : [VOTRE NUMÉRO DE COMPTE]
- Numéro de facture : [NUMÉRO DE FACTURE]
- Montant : [MONTANT]
- Période : [PÉRIODE]

Demande :
- Pouvez-vous examiner cette facture et voir si une réduction ou annulation est possible ?
- Je suis prêt à fournir des explications supplémentaires si nécessaire
- Je comprends que j'aurais dû mieux surveiller mes coûts, mais j'étais en phase de test

Je comprends que j'aurais dû mieux surveiller mes coûts, mais j'étais en phase de test et j'ai mal configuré les services.

Merci de votre compréhension.

Cordialement,
[Votre nom]
[Votre email]
```

---

## 🇬🇧 VERSION ANGLAISE (Recommandée)

**Subject** :
```
Request for billing adjustment - Test account without cost control
```

**Message** :
```
Hello,

I am contacting AWS regarding a significant bill on my AWS account [ACCOUNT NUMBER].

Context:
- I created this AWS account to test an application in development
- I did not have control over the costs and services used
- The bill amounts to over $600 while I was only testing the application
- I do not have the means to pay this bill
- I was not aware of the real costs of the services used

Details:
- Account number: [YOUR ACCOUNT NUMBER]
- Invoice number: [INVOICE NUMBER]
- Amount: [AMOUNT]
- Period: [PERIOD]

Request:
- Can you review this invoice and see if a reduction or cancellation is possible?
- I am ready to provide additional explanations if necessary
- I understand that I should have better monitored my costs, but I was in a testing phase

I understand that I should have better monitored my costs, but I was in a testing phase and I misconfigured the services.

Thank you for your understanding.

Best regards,
[Your name]
[Your email]
```

---

## 📋 INFORMATIONS À PRÉPARER

**Avant d'envoyer le message, rassemblez** :
- ✅ Numéro de compte AWS
- ✅ Numéro(s) de facture(s)
- ✅ Montant total
- ✅ Période de facturation
- ✅ Services utilisés (si possible)
- ✅ Explication de l'utilisation

---

## 🔗 OÙ ENVOYER

**Via AWS Console** :
1. https://console.aws.amazon.com/support/home
2. Cliquer sur **"Create case"**
3. Sélectionner **"Account and billing support"**
4. Coller le message ci-dessus
