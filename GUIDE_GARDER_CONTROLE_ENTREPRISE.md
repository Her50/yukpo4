### MÉCANISME 5 : VESTING ALIGNÉ (Protection Mutuelle)

**Principe** : Vos actions se "débloquent" progressivement (4 ans) MAIS vous restez CEO

```
VESTING STANDARD
────────────────

Durée totale : 4 ans
Cliff : 1 an

Comment ça marche :

Année 1 (0-12 mois) : 0% vested
└─ Si vous quittez : Vous perdez TOUT
└─ Si investisseurs vous virent : Clause accélération

Après 1 an (cliff) : 25% vested
└─ Vous avez "gagné" 25% de vos actions

Mois 13-48 : 2.08% par mois
└─ Progression linéaire

Après 4 ans : 100% vested
└─ Toutes vos actions sont définitives
```

**MAIS ATTENTION : Négocier ACCÉLÉRATION en cas licenciement**

```
CLAUSE D'ACCÉLÉRATION (Essentielle!)
────────────────────────────────────

"SINGLE TRIGGER ACCELERATION :

En cas de révocation du Fondateur sans faute grave, 
100% des actions non-vestées deviennent immédiatement vestées.

Exemple :
Vous êtes à 50% vesting (2 ans écoulés)
Investisseurs vous virent sans raison valable
→ Les 50% restants se débloquent immédiatement
→ Vous partez avec 100% de vos actions ✅

DOUBLE TRIGGER ACCELERATION :

En cas de vente de l'entreprise (acquisition), 
50-100% des actions non-vestées s'accélèrent.

Exemple :
Vous êtes à 75% vesting (3 ans écoulés)
Orange rachète Yukpomnang
→ Les 25% restants se débloquent
→ Vous vendez 100% et encaissez pleinement ✅"

À NÉGOCIER :
└─ Single trigger : OUI (protection licenciement)
└─ Double trigger : OUI (protection acquisition)
```

**POURQUOI C'EST IMPORTANT ?**

```
SCÉNARIO CAUCHEMAR SANS ACCÉLÉRATION :
──────────────────────────────────────

Année 2 (50% vested)
Investisseurs vous virent injustement
Ils gardent vos 50% non-vested (50M FCFA volés!)
Vous partez avec seulement 50% ❌

AVEC CLAUSE ACCÉLÉRATION :
─────────────────────────

Année 2 (50% vested)
Investisseurs vous virent injustement
→ Accélération : 100% vested immédiatement
Vous partez avec 100% de vos actions ✅
+ Indemnités : 24 mois salaire
+ Ils réfléchissent 2x avant de vous virer (coûteux pour eux)
```
