# 📋 Commandes : Tester Différents Formats de Nom

**Date** : 2026-02-14  
**Usage** : Formats à essayer pour le nom de la carte

---

## 🔄 FORMATS À ESSAYER (dans l'ordre)

### Format 1 : Majuscules Complètes
```
LELE HERNANDEZ
```

### Format 2 : Première Lettre Majuscule
```
Lele Hernandez
```

### Format 3 : Tous en Majuscules (Sans Espace)
```
LELEHERNANDEZ
```
*(Si la carte n'a pas d'espace)*

### Format 4 : Avec Prénom Complet
```
[VOTRE PRENOM COMPLET] HERNANDEZ
```

### Format 5 : Format Inversé
```
HERNANDEZ LELE
```

### Format 6 : Initiale du Prénom
```
L. HERNANDEZ
```

---

## ⚠️ IMPORTANT

**Le nom doit correspondre EXACTEMENT à la carte** :
- ✅ Vérifier la carte physique
- ✅ Respecter les majuscules/minuscules
- ✅ Respecter les espaces
- ✅ Respecter les accents

---

## 🔍 VÉRIFICATION

**Sur votre carte Visa, le nom apparaît comme** :

- `HERNANDEZ LELE` ?
- Autre format ?
