# 🖱️ Étapes pour Configurer les Quotas Places API

**Date** : 2026-02-19

---

## ✅ Étape 1 : Cliquer sur la Carte "Places API (New)"

**Action** : Cliquez sur la **carte entière** "Places API (New)" (pas sur un lien spécifique)

**Ce que vous voyez** :
- Carte avec titre "Places API (New)"
- Description : "Next generation of the Places API with access to more than 200 million places"
- Bouton "Disable" en haut à droite
- Liens : Keys, Metrics, Guides

**👉 CLIQUEZ SUR LA CARTE ENTIÈRE** (n'importe où sur la carte, sauf sur les liens)

---

## ✅ Étape 2 : Aller dans l'Onglet "Quotas"

Après avoir cliqué sur la carte, vous serez sur la page de détails de "Places API (New)".

**Vous verrez plusieurs onglets en haut** :
- Overview (Vue d'ensemble)
- **Quotas** ← **CLIQUEZ ICI**
- Credentials (Identifiants)
- etc.

**👉 CLIQUEZ SUR L'ONGLET "QUOTAS"**

---

## ✅ Étape 3 : Modifier les Quotas

Sur la page Quotas, vous verrez une liste comme :

- ✅ Requests per day (Requêtes par jour)
- ✅ Requests per minute (Requêtes par minute)
- ✅ Requests per 100 seconds (Requêtes par 100 secondes)

### Pour modifier :

1. **Cochez la case** à gauche du quota (ex: "Requests per day")
2. **Cliquez sur "EDIT QUOTAS"** (bouton en haut)
3. **Entrez la nouvelle limite** :
   - Requests per day : `50000`
   - Requests per minute : `100`
   - Requests per 100 seconds : `200`
4. **Justification** :
   ```
   Limitation pour éviter les coûts excessifs suite à un bug de code.
   Application en développement avec un seul testeur.
   ```
5. **Cliquez sur "SUBMIT"**

---

## 🎯 Résumé Rapide

1. **Cliquez sur la carte "Places API (New)"** (la carte entière)
2. **Cliquez sur l'onglet "Quotas"**
3. **Cochez le quota** que vous voulez modifier
4. **Cliquez sur "EDIT QUOTAS"**
5. **Entrez les limites** et **soumettez**

---

## ⚠️ Alternative : Lien "Metrics"

Si vous préférez, vous pouvez aussi cliquer sur le lien **"Metrics"** (l'icône de graphique en barres) sur la carte "Places API (New)". Cela vous amènera aux métriques, et vous pourrez naviguer vers les quotas depuis là.

Mais la méthode la plus directe est de **cliquer sur la carte** puis sur l'onglet **"Quotas"**.
